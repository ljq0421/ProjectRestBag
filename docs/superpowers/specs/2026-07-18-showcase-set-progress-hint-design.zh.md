# 橱窗套装进度提示设计

## 目标

在橱窗页面左上方持续展示当前上架商品可参与的全部候选套装，让玩家在调整陈列时直接看到套装是否生效，以及距离生效还差多少商品或是否只差连通摆放。

本改动只作用于 `project-rest-new`，不改变套装加成数值、套装配置、营业结算或存档结构。

## 展示位置与样式

- 在 `scenes/ui/storefront/showcase_board.tscn` 中新增稳定的多行标签 `SetProgressLabel`。
- 标签位于 `RoundControlBar` 紧下方、`ShowcasePulseSummary` 上方，文字左对齐。
- 每个候选套装独占一行。
- 没有候选套装时隐藏标签，不占用额外垂直空间。
- 场景文件拥有节点、布局和静态样式；`scripts/main_view.gd` 只绑定节点并刷新文字与可见性。

## 候选与状态规则

套装规则继续以 `doc/display_rules_full.json` 的 `set_bonuses` 为唯一配置来源，并沿用现有套装契约：商品数量达到 `min_item_count`、覆盖全部 `required_tags`，且参与商品在橱窗中四方向连通。

候选套装定义为：当前至少有一件上架商品包含该套装的任一必需标签。没有任何上架商品贡献标签的套装不显示。

每个候选套装显示以下三种状态之一：

1. 当前套装计算结果已包含该套装的稳定分组 ID：显示 `套装「名称」生效`。
2. 当前商品数量或标签覆盖仍不完整：显示 `套装「名称」还差 N 件`。
3. 商品数量与标签覆盖已完整，但现有摆放没有形成套装要求的连通组合：显示 `套装「名称」还差连通摆放`。

`N` 表示要同时补足最低商品数和缺失必需标签所需的最少商品数。计算时在配方目录的标签组合中寻找最小补充组合，使“当前贡献商品 + 补充商品”同时满足最低商品数和全部必需标签：

```text
N = 满足最低商品数与全部必需标签覆盖所需的最小补充商品数
```

同一件商品可以覆盖多个必需标签，因此不能简单把缺失标签数当作商品数。如果配方目录中不存在能覆盖某个缺失标签的商品，则使用保守回退值 `max(最低商品数缺口, 缺失标签数)`，避免显示为已经具备。

## 排序

多行提示按以下顺序稳定排列：

1. 已生效套装优先。
2. 未生效套装按缺少件数从少到多排列；“还差连通摆放”排在缺少 `0` 件的位置。
3. 状态相同时保持 `set_bonuses` 的配置顺序。

## 组件与数据流

在 `ShowcaseRuleService` 中增加一个纯计算入口，输入当前陈列状态、配方数据和套装规则，输出按配置顺序生成的候选进度条目。每个条目至少包含：

- `set_id`
- `set_name`
- `status`：`active`、`missing_items` 或 `needs_connection`
- `missing_count`
- `config_order`

该入口复用现有套装计算结果中的 `breakdown.set.groups` 判断真实生效状态，不另写第二套“是否生效”规则。

`main_view.gd` 在 `_refresh_storefront_showcase()` 的既有刷新链路中调用套装进度计算入口，将结果格式化为多行中文文字，并更新 `SetProgressLabel`。因此上架、下架、拖动换位和其他会触发橱窗刷新的操作都会同步更新提示。

## 异常与边界

- `state`、配方或套装规则为空时返回空数组，界面隐藏提示。
- 已上架但库存为零的陈列项仍按现有橱窗布局规则参与套装判定，保持与实际套装加成计算一致；本功能不单独改变售罄商品语义。
- 不修改现有 `ShowcasePulseSummary` 的阶段、热度和库存职责。
- 不增加弹窗、点击行为、存档字段或新的套装规则。

## 测试与验收

先新增聚焦自检并确认红灯，再实现最小代码使其转绿。测试覆盖：

- 至少贡献一个必需标签的套装会成为候选，无关套装不会显示。
- 多个候选套装会生成多行结果。
- 商品或标签不足时得到正确的最少缺少件数。
- 数量和标签齐全但没有连通时得到 `needs_connection`。
- 套装真实生效时得到 `active`，且使用现有稳定套装 ID。
- 多候选结果按“生效、缺少件数、配置顺序”稳定排序。
- `SetProgressLabel` 存在于场景中的指定位置，左对齐并支持多行。
- 完整刷新后标签文字与可见性符合计算结果。

聚焦自检通过后，运行相关橱窗布局/规则回归以及项目最小 Godot 启动检查。所有 Godot 无头命令必须显式传入位于可写目录的 `--log-file`。
