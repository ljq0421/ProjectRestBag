# 研发笔记迁入研发结果弹窗设计

**日期：** 2026-07-23  
**项目：** `project-rest-new`  
**状态：** 已确认

## 目标

把“研发制作”页面中常驻的“研发笔记”移入点击“研发”后出现的等待/结果弹窗，减少页面上方长期占用的空间，同时让线索与产生它的研发结果直接关联。

## 已确认的交互规则

- “研发制作”页面不再显示常驻的研发笔记面板。
- 点击“研发”后仍立即打开现有弹窗，并先显示等待状态。
- 多材料研发失败后，弹窗切换到结果状态，并在失败消息下方显示研发笔记。
- 弹窗中的笔记使用本次研发结算后的已保存最新线索状态，包括线索等级、目标配方、正确设备和材料状态等现有内容；本次没有提升线索时，仍可显示此前保存的最新有效笔记。
- 如果结算后仍不存在任何有效笔记，失败弹窗显示“研发笔记｜暂无有效线索”和现有的无有效线索说明。
- 多材料研发成功时只显示现有的配方图标、名称和成功消息，不显示研发笔记。
- 单材料加工继续使用同一个等待/结果弹窗，但任何状态都不显示研发笔记。
- 玩家仍必须点击结果弹窗中的“确认”按钮才能关闭弹窗并继续后续通知队列。

## 场景与职责

### 研发制作页面

从 `scenes/ui/pages/workbench_pages.tscn` 删除 `ResearchHintPanel`、`ResearchHintTitle` 和 `ResearchHintBody`。移除面板后，配方列表自然获得释放出的纵向空间。

页面标题区只保留研发输入提示，不再展示线索等级、目标配方或“可按研发笔记准备材料”等笔记摘要，避免笔记内容在弹窗外残留一份。

### 研发等待/结果弹窗

在 `scenes/ui/overlays/research_progress_dialog.tscn` 的结果内容中新增场景声明的笔记信息容器，并包含标题与正文节点。该容器使用普通 `VBoxContainer`，不使用 `PanelContainer`、背景贴图、边框或 `DessertInsetPanel` 视觉类型，并默认隐藏。

笔记容器不声明会撑大弹窗的额外最小高度。`520×420` 继续作为 `popup_centered(...)` 的原始请求尺寸，但不再通过窗口 `min_size/max_size` 强制锁定；Godot 可以像改动前一样按既有内容最小尺寸调整实际运行尺寸。等待态打开后的实际窗口尺寸作为本次弹窗的基准，研发成功、研发失败和单材料加工状态必须始终保持同一基准尺寸。

等待、研发成功、单材料加工及不带笔记的普通结果继续使用现有居中结果容器，原有内容位置不变。“研发失败＋笔记”使用独立的无外框失败内容区：该内容区填满 `StateContent`，左右边界对称，并从内容区顶部稳定排列失败消息、笔记标题和笔记正文。笔记的显隐不再参与普通居中结果容器的尺寸计算，避免整组文字向右、向下偏移。

`scripts/ui/overlays/research_progress_dialog.gd` 负责：

- 进入等待状态时清空并隐藏笔记；
- 显示加工结果或研发成功结果时隐藏笔记；
- 显示研发失败结果时隐藏普通居中结果容器，并在独立失败内容区显示失败消息、笔记标题和正文；
- 每次状态切换时重置上一次结果，防止加工、成功研发和失败研发之间串留内容。

弹窗只负责展示传入内容，不读取游戏状态，也不生成研发线索。

### 主界面协调

`scripts/main_view.gd` 继续负责线索数据与玩家可读文案之间的转换。研发结算完成后：

1. 沿用现有 `RecipeBook.research(...)` 完成研发并更新状态。
2. 对研发失败结果读取结算后的最新 `RecipeBook.research_hint_view(...)`。
3. 复用现有笔记标题和正文格式，将结果传给研发弹窗。
4. 对加工结果和研发成功结果调用不带笔记的现有结果展示路径。

现有 `research_hint_progress`、`latest_research_hint_recipe_id`、线索升级规则和存档结构保持不变。

## 数据流

```text
点击研发
  -> 弹窗显示等待状态并隐藏笔记
  -> 研发计时完成
  -> RecipeBook 结算并更新线索状态
  -> 成功：弹窗显示配方结果，不显示笔记
  -> 失败：MainView 格式化最新线索，弹窗显示失败消息和研发笔记
  -> 点击确认
  -> 关闭弹窗、解除忙碌状态、继续通知队列
```

单材料输入走加工分支，不查询也不传递研发笔记。

## 异常与边界处理

- 无效输入或未选择设备时，沿用当前页内状态提示，不打开弹窗。
- 研发失败且状态中没有任何有效线索时，弹窗显示明确的“暂无有效线索”笔记，不伪造目标配方。
- 保存失败时，仍保留当前研发结果和笔记内容，并沿用现有存档失败反馈。
- 弹窗从失败结果切换到下一次等待、成功或加工结果时，必须清空旧笔记。
- 研发结果弹窗可见期间，继续阻止全局通知弹窗抢占显示。
