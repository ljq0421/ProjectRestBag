# 甜品店橱窗系统设计（背包乱斗式摆放+相邻加成）
## 一、橱窗基础规则
- **规格**：5行 × 10列 = 50个标准格子，整体为横向长方形陈列柜
- **摆放规则**：成品拖拽上架，支持90°旋转调整方向，格子不可重叠；产品售出后对应格子空出，补货自动归位
- **相邻判定**：仅上下左右**四方向邻接**算有效相邻，斜角不计，与《背包乱斗》判定逻辑一致
- **核心循环**：玩家通过调整摆放形状、搭配相邻组合，在有限格子内最大化「单位时间总收益」，兼顾售价与售速双维度

## 三、相邻加成与减损体系
整体遵循「**搭配有增益、扎堆有内卷、冲突有惩罚**」的原则，分4层规则，可叠加生效，保证策略深度。

### （一）基础标签联动（全局生效，两两触发，双向加成）
所有带对应标签的产品相邻即触发，双向生效，多组相邻可叠加；是最基础的布局逻辑。

| 触发标签组合 | 效果（双方同时生效） | 设计逻辑 |
|--------------|----------------------|----------|
| 「果香」 + 「清爽」 | 售价 +8%，售速 +5% | 夏日清新组合，视觉和口感适配，客户决策成本低 |
| 「苦甜」 + 「浓郁」 | 售价 +10% | 醇厚风味组合，符合下午茶消费场景，客单价更高 |
| 「甜」 + 「咸香」 | 售价 +12%，售速 +8% | 咸甜对冲提升食欲，客户会同时购买两类，是核心联动 |
| 「软糯」 + 「甜」 | 售价 +5%，售速 +10% | 软糯甜食受众广、复购高，主打走量 |
| 「茶香」 + 「乳制」 | 售价 +10% | 奶茶/茶奶冻天然适配，符合大众口味习惯 |
| 「香脆」 + 「浓郁」 | 售价 +7% | 口感层次对比，食用体验更好，溢价接受度高 |
| 「经典」 + 「经典」 | 售速 +6% | 经典款组合辨识度高，老客闭眼买，提升出货速度 |
| 「低负担」 + 「清爽」 | 售价 +7%，售速 +7% | 健康轻食组合，健身客群愿意为搭配付费 |

### （二）进阶套装组合（凑齐触发，额外全局加成）
当指定品类的产品两两相邻、形成完整组合时，触发套装额外加成；可与基础标签联动叠加，是玩家build的核心目标。

| 套装名称 | 组成要求（需两两相邻） | 套装效果 | 适配流派 |
|----------|------------------------|----------|----------|
| 【经典下午茶三件套】 | 1款茶类饮品 + 1款曲奇/酥饼 + 1款蛋糕/派 | 三件总售价 +15%，售速 +10% | 均衡利润流 |
| 【夏日清凉套】 | 2款果香甜品 + 1款薄荷/清爽饮品 | 全组售速 +20% | 走量流 |
| 【老街怀旧套】 | 2款米食/传统糕点 + 1款甜汤/糊类 | 全组售价 +12% | 经典客群流 |
| 【健身轻食套】 | 2款低负担食品 + 1款酸奶/燕麦碗 | 全组售价 +10%，售速 +15% | 健康客群流 |
| 【巧克力狂热套】 | 2款可可/巧克力甜品 + 1款坚果类 | 全组售价 +18% | 高客单价流 |
| 【咸甜正餐套】 | 1款咸口主餐（焗饭/派/饺） + 1款饮品 + 1款小甜品 | 全组售速 +18%，主餐售价 +5% | 综合营收流 |
| 【全茶风味套】 | 2款不同茶底甜品（红茶/绿茶/抹茶） | 全组售价 +13% | 茶香主题流 |

> 触发规则：套装内所有产品必须至少与另外1件相邻，形成连通整体即可；同一件产品可参与多套套装，叠加生效。

### （三）冲突减损规则（负面效果，避免无脑堆叠）
防止玩家全堆同品类高价款，强制要求搭配，提升布局策略性。

1. **同类扎堆惩罚**
    - 同标签产品连续≥3个紧密相邻（横向/纵向连成一片）：每超出2个的部分，每件售价 -5%，售速 -3%
    - 例：4个曲奇挨在一起，第3、4个各触发-5%售价惩罚
    - 设计逻辑：同类产品过多会让客户选择困难，反而降低购买欲

2. **口感冲突惩罚**
    - 「薄荷/清凉」类产品 与 「浓郁芝士/黄油」类产品相邻：双方售价 -8%
    - 例：薄荷慕斯旁边放芝士蛋糕，双向减益
    - 设计逻辑：气味和口感反差过大，客户觉得违和，降低购买意愿

3. **饱腹压制惩罚**
    - 1个咸口主餐（焗饭/大份派）周围相邻≥3款甜甜品：所有甜甜品售速 -5%
    - 设计逻辑：吃完主餐有饱腹感，甜品购买欲下降，符合真实消费逻辑

### （四）橱窗位置加成（固定位置增益，布局策略核心）
5×10的橱窗划分3个功能区，放在不同位置有固定属性加成，引导玩家做「引流款-利润款」分层布局。

| 区域 | 位置 | 固定效果 | 摆放建议 |
|------|------|----------|----------|
| 引流位 | 第1行（最靠近顾客的第一排） | 所有产品售速 +8%，售价 -3% | 放低价走量款、爆款小食，吸引顾客进店 |
| 黄金C位 | 第2-4行、第3-8列（中间3×6区域） | 所有产品基础售价 +5%，相邻加成效果 +20% | 放招牌款、套装核心件，最大化加成收益 |
| 宝藏位 | 第5行（最深处一排） | 所有产品售价 +8%，售速 -4% | 放高价款、招牌大蛋糕，靠高利润取胜 |

## 四、玩法流派与平衡设计
基于以上规则，可衍生出4种主流玩法流派，各有优劣，无绝对最优解，保证可玩性和重复游玩价值：

1. **缝隙走量流**
    - 思路：全摆1格迷你曲奇、果冻，塞满所有格子，靠数量+售速加成取胜
    - 优势：格子利用率100%，售速极快，现金流稳定
    - 劣势：单品利润低，客单价上限不高

2. **招牌利润流**
    - 思路：C位放2-3个大份招牌款，周围围一圈加成辅助件，靠高单价+高叠加溢价取胜
    - 优势：单笔收益极高，适合后期解锁招牌后使用
    - 劣势：售速慢，空窗期长，格子利用率低

3. **主题套装流**
    - 思路：凑2-3套完整组合（比如下午茶套+夏日套），围绕套装做布局，吃满套装加成
    - 优势：加成稳定，综合收益最高，适配大多数客群
    - 劣势：对解锁进度要求高，需要凑齐对应配方

4. **咸甜综合流**
    - 思路：穿插摆放咸口主餐和甜品饮品，靠「咸甜联动」大幅提升售速，兼顾主食和甜品营收
    - 优势：客群覆盖广，抗波动能力强
    - 劣势：单品类加成不极致，需要平衡两类产品比例

### 补充扩展设计（后期可迭代）
1. **橱窗皮肤/主题**：不同主题橱窗对特定标签产品额外加成，比如夏日主题加成果香、复古主题加成经典
2. **陈列道具**：解锁蛋糕架、冷藏展示柜等道具，可占用格子但给周围产品全局加成
3. **每日偏好**：每日随机刷新「今日热门标签」，对应标签产品售速+15%，引导玩家每日调整布局
