# 第 16–25 个配方进阶图标 ImageGen 提示词（project-rest-new）

> **当前状态（2026-07-22）：** 稳定款已从游戏删除。原第一进阶档内容仅作历史记录，不再生成或交付；当前有效范围只有人气款与招牌款。

## 使用方式

每次把“通用基础提示词”与一个配方档位的“专属提示词”一起提交给 ImageGen，并上传该配方的试作品 PNG 为 `Image 1`。`Image 1` 只作身份、画风、略俯视视角、描边和材质参考，不是编辑目标。

`1×1`、`1×2`、`2×1`、`2×2` 输出 **512×512 px**；`2×3` 输出 **768×768 px**。稳定与第二档继承试作品布局；最高档只采用配置中明确覆写的布局。

## 通用基础提示词

```text
Use case: stylized-concept。Asset type: 2D 卡通经营游戏配方图标。保持 Image 1 的温暖深可可棕描边、圆润造型、半手绘赛璐璐加轻厚涂质感；生成全新进阶图标，不要照片感或 3D 渲染。
输出指定像素尺寸、带 alpha 通道的透明 PNG；四角和未占用格完全透明。禁止绿色、白色、黑色或任何纯色背景，禁止桌面、地面、场景、投影、外发光、光环、粒子和闪粉。不要文字、数字、字母、Logo、水印、边框、徽章、旗帜、吊牌、皇冠、星星或丝带。原材料只能作为贴近主体的小型辅助装饰，不遮挡主体、不成为第二份主食、不散落为背景；不要加入配方表以外的食材、餐具或容器。
```
