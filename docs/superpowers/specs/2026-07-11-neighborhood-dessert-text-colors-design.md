# 邻里甜点 UI 文字配色修复设计

## 问题

当前浅色“邻里甜点”皮肤只为部分 `Dessert*` 主题变体定义了文字颜色。普通 `Label`、未使用专用变体的 `Button`、输入控件等仍继承 Godot 默认白色，在奶油色面板上对比度不足。

## 方案

在 `neighborhood_dessert_theme.tres` 中补齐常用基础控件的全局文字颜色，而不是逐个场景节点添加覆盖：

- 普通正文、按钮与可编辑文字使用深咖啡色，保证浅色背景上的可读性。
- 次要提示、禁用状态和不可编辑状态使用较浅的棕灰色，仍保持足够对比度。
- 悬停、按下、聚焦和选中状态使用同一暖棕色系，避免交互时回退为白色。
- 红色主按钮、深色选中标签、积极状态徽章继续使用现有奶白色文字。
- 橱窗中特意使用的金色价格/强调文字保持不变。

覆盖范围包括当前场景中实际使用的 `Label`、`RichTextLabel`、`Button`、`CheckBox`、`CheckButton`、`LineEdit`、`TextEdit`、`OptionButton`、`SpinBox`、`TabBar` 和 `ItemList` 等基础控件。

## 验证

先扩展主题自检，使其在修改主题前能明确报告基础控件仍为白色；随后补充主题颜色并验证：

1. 浅色背景上的基础控件不再使用纯白文字。
2. 普通、悬停、按下、禁用、选中和只读状态均有明确颜色。
3. `DessertPrimaryButton`、`DessertTopTabButton` 选中态和积极徽章仍保留奶白色。
4. 运行主题聚焦自检与最小项目加载检查，确认资源和场景可正常解析。

## 非目标

本次不调整字体、字号、布局、贴图、控件结构，也不覆盖已有的业务状态色和强调色。
