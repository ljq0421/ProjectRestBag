# 橱窗甜品店背景设计

## 目标

为 `project-rest-new` 主界面左侧整个 `Root/Body/MainArea/StorefrontPanel` 增加一张与现有游戏画风一致的甜品店背景，在不改变 14×12 橱窗几何、商品摆放规则和现有交互反馈的前提下，强化“这是一个甜品店橱窗”的场景识别。

## 已确认的视觉方向

- 采用“清爽店面背景”构图：装饰集中在顶部和外沿，中央区域保持简洁。
- 顶部使用粉色、奶油黄、薄荷绿与奶油白相间的多巴胺条纹雨篷。
- 不放置 `SWEET`、店名、招牌或其他文字。
- 两侧使用少量暖光小灯和甜品装饰，装饰不得侵入商品主要识别区。
- 背景覆盖整个左侧面板，包括橱窗标题、营业控制信息和商品网格后方。
- 从面板顶部到 `ShowcaseGrid` 顶部绘制一整块约 70% 不透明度的奶油色圆角遮罩，使顶部信息清晰可读，同时允许雨篷颜色轻微透出。
- 画风为简约、可爱、扁平插画，使用圆润轮廓、焦糖棕描边和柔和奶油底色，与现有 `neighborhood_dessert` 主题一致。
- 不使用写实材质、复杂透视、人物、品牌标识、水印或高频背景纹理。

## 构图与尺寸

- 背景资源保持 `1008×864`、宽高比 `7:6`，运行时以等比 `cover` 方式铺满整个 `StorefrontPanel` 的实际矩形；宽高比不同时只裁切少量外沿，不做非等比拉伸。
- 当前 `StorefrontPanel` 只有一个铺满区域的 `ShowcasePanel` 子节点，因此在 `ShowcasePanel` 根矩形中绘制背景，视觉上即覆盖完整 `StorefrontPanel`。
- 雨篷位于画面顶部，控制在画面高度约 12% 至 16%，进入标题和营业控制信息后方，但由奶油色遮罩保证文字可读性。
- 小灯和甜品装饰只放在左右外沿与下方角落，中央约 80% 区域保持低对比、低细节。
- 背景不包含格子线、商品、按钮、文字或状态标识；现有 14×12 交互格子继续作为独立 UI 层绘制。
- 最终项目资源输出为 PNG，并缩放或裁切到 `1008×864`；运行时同样保持比例，不得拉伸变形。

## 场景接入

- 在 `scenes/ui/storefront/showcase_board.tscn` 中继续由场景文件拥有稳定的背景资源引用，并增加场景拥有的顶部奶油遮罩样式。
- 背景绘制到 `ShowcasePanel` 根节点完整矩形，标题、营业控制信息、网格、商品图标、状态徽章、拖拽预览和营业反馈继续位于上层。
- 顶部遮罩从根节点顶部延伸到 `ShowcaseGrid` 顶部；套装进度或扩建工具条显隐导致网格移动时，遮罩范围必须同步重绘。
- `ShowcaseGrid` 的 14 列、`1008×864` 最小尺寸、单格尺寸和直接完整展示约束保持不变，不增加滚动容器。
- 若新增父级容器导致节点路径变化，只更新必要的绑定路径和对应聚焦检查，不重构无关的橱窗逻辑。

## 格子透明度

- 橱窗格子采用半透明奶油底色，让背景能够柔和透出。
- 优先通过 `ShowcaseSlot` 根按钮的 `self_modulate` 调整格子自身透明度，避免透明度传递到子节点。
- 商品图标、名称、状态徽章、售卖进度、预览碎片和反馈描边保持现有不透明度与颜色逻辑。
- 锁定、奖励、悬停、按下等状态继续使用现有主题变体；透明处理不得破坏状态区分。

## 图片生成规范

使用内置 `imagegen` 生成单张项目背景。提示词必须包含以下约束：

- 用途：游戏 UI 橱窗背景，`stylized-concept`。
- 主题：可爱简约的街角甜品店橱窗。
- 配色：草莓粉、奶油黄、薄荷绿、奶油白，辅以焦糖棕描边。
- 构图：顶部多色条纹雨篷；两侧小型暖光灯；角落少量蛋糕、布丁或糖果装饰；中央大面积安静留白。
- 风格：扁平插画、圆润轮廓、低纹理、柔和阴影，与当前游戏 UI 一致。
- 禁止：任何文字、店牌、人物、品牌、Logo、水印、格子、货架、商品陈列、复杂室内景深或写实摄影效果。

内置工具生成后，将选定图片复制进项目资源目录，再做必要的无损裁切或高质量缩放。项目不得引用仅存在于 Codex 生成目录中的文件。

## 验证

- 增加或更新聚焦自检，验证背景资源存在、背景覆盖契约指向整个根面板、顶部遮罩样式存在、`ShowcaseGrid` 仍为 14 列且最小尺寸保持 `1008×864`。
- 验证 `ShowcaseSlot` 的半透明处理只作用于根按钮，不改变商品图标和状态子节点的不透明度契约。
- 按项目约定从 `project-rest-new` 目录运行最窄匹配的 Godot headless 自检，并为命令传入可写的 `--log-file`。
- 启动场景做视觉检查：背景铺满整个左侧面板、雨篷进入顶部信息区、奶油遮罩保证标题和营业信息清晰、商品与状态文字清晰、右侧工作台布局不受影响。
- 运行 `git diff --check`，确认没有空白符错误。

## 验收标准

- 整个左侧 `StorefrontPanel` 一眼可识别为甜品店店面，整体观感简约、可爱、多巴胺，不能只在网格矩形内显示背景。
- 无 `SWEET` 或其他图片内文字。
- 粉、黄、薄荷绿雨篷明确可见，装饰集中在边缘，中央不喧宾夺主。
- 标题、营业控制、套装进度和热度信息位于连续奶油色半透明遮罩上，保持清晰可读。
- 背景能透过半透明格子柔和显示，但商品图标、状态、拖拽和营业反馈仍清晰可读。
- 14×12 网格、`1008×864` 几何、完整直显和现有橱窗交互均保持不变。
- 资源保存在 `project-rest-new` 内，并由 `.tscn` 稳定引用。

## 不在本次范围

- 不修改右侧采购、产出、研发或橱窗经营页面。
- 不调整橱窗扩建、摆放、售卖、套装、冲突、主题或成长规则。
- 不更换商品图标、按钮皮肤、字体、顶部状态栏或全局主题。
- 不制作多套可切换背景；草莓粉加奶油黄方案仅作为未来备选，不在首版同时接入。
