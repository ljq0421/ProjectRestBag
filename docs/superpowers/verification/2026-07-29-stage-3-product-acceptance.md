## 自动化能说明什么

### 已确认

- 四次三选一的 81 条候选位置序列都能走完五场，不会出现空候选、无效配置或卡死。
- 鼠标可以完成 Hub → 五场备战/战斗/战报/强化 → 总结 → 研究解锁 → 下一局。
- 强化数量、强化名称、研究收益和下一局永久配方变化均有明确的玩家侧反馈。
- 三类强化标签“适配当前构筑 / 通用强化 / 转型路线”已经在选择页区分。

### 合理推测，但不是产品结论

- 相向压力条、需求窗口结算与本局构筑总结，应该比原先更容易形成“战斗”和“变强”的因果感。
- 永久研究节点出现在下一局备货池，具备形成重开目标的基础。

### 暂时无法验证

- 玩家是否真的在三张强化卡之间犹豫，而不是永远选择最大数值。
- 强化是否实际促使玩家重排，而不是只在数字上变强。
- 玩家是否主观感到明显变强。
- 完成短链后是否愿意立刻重开。
- 三类构筑方向是否都具有吸引力。

这些问题必须由真实玩家记录，不能由自检、截图或 AI 代替。

## 真人通过条件

沿用已确认的设计规格：

- 新玩家约 2 分钟理解“看需求 → 摆放 → 自动战斗 → 调整”。
- 完整短链平均 15–20 分钟。
- 每次失败都能指出具体窗口或截止条件。
- 四次强化都能看见构筑变强。
- 至少两次强化促使重排或改变挑战备货。
- 至少三类构筑方向可行。
- 玩家理解研究树是规划永久配方，而不是随机领奖。

任一止损信号出现时，不应继续扩配方或做无尽模式：

- 五场只被理解为挑剔值逐级增加。
- 所有强化都只选最高百分比。
- 玩家仍只能归因于“数值不够”。
- 玩家完成后没有可描述的下一局目标。
