# 前 5 个配方进阶图标 ImageGen 提示词（project-rest-new，v3）

> **当前状态（2026-07-22）：** 稳定款已从游戏删除。本文中的稳定款段落仅作历史记录，不再生成或交付；当前有效范围只有人气款与招牌款。

## 使用方式

- 每次只生成一个图标，并将对应的试作品 PNG 作为 `Image 1` 上传。
- 本文档面向 `project-rest-new`：试作品路径相对该项目根目录，布局以 `doc/recipe_display_config.json` 为准，原材料以 `scripts/catalog.gd` 为准。
- `Image 1` 仅用于配方身份、画风、视角、描边和材质表现参考，不是编辑目标。
- 每段提示词都包含完整约束，可以单独复制给 ImageGen；v3 覆盖旧版中与透明背景、文字或等级装饰冲突的限制。
- 输出必须是带 alpha 通道的透明 PNG：画布四角完全透明，绝不使用绿色、白色、黑色或任何纯色背景，也不出现地面、投影或场景。
- 递进原则：稳定款使用 2–3 种主色、1 个轻量装饰和至多 1 组微小原料点缀；人气款使用 4–5 种更明快的色彩、至少 2 个装饰和 1–2 组可见原料；招牌款使用 5–6 种最丰富的色彩、至少 3 个装饰和多组可见原料，主体轮廓也要更夸张。档位差异必须来自造型、色彩、装饰和食材组合，不能依赖任何文字标签。
- 文档中的“稳定款 / 人气款 / 招牌款”只用于说明档位；生成出的图标本身禁止出现任何文字、数字、标签文字、Logo 或水印。

## 四档布局、继承与尺寸规则

- 每个配方有四款图标：试作品、稳定款、人气款、招牌款。
- `stable` 与 `popular` 的 `recipe_name`、`cell_count`、`shape_category`、`default_shape`、`rotatable`、`remark` 全部继承试作品；`signature` 仅覆写其 `growth_variants.signature` 明示的字段，其余字段同样继承试作品。
- 布局边界不超过 `3×3`。所有最大边不超过 2 格的布局（`1×1`、`1×2`、`2×1`、`2×2`）输出 **512×512 px** 透明 PNG；任一边为 3 格的布局（`1×3`、`2×3`、`3×3`、`3×2`、`3×1`）输出 **768×768 px** 透明 PNG。格子按每格 256 px 计算。
- 生成主体必须严格填满提示词指定的连续占格；未占用格保持完全透明。不得把 `1×2` 或 `2×1` 画成近方形，也不得把 `2×3` 或其他 3 格边长布局缩成 512×512。

## 1. 米浆饮（rice_milk_drink）

试作品参考：`resources/recipe_icons/rice_milk_drink.png`  
图标占格方向：试作品、稳定款、人气款、招牌款均继承竖杯款 `2×1`，输出 512×512 px。

### 稳定款

```text
任务：为游戏配方“米浆饮”生成全新的“稳定款”图标。

输入图片：Image 1 是同一配方的试作品图标，仅作为配方身份和画风参考，不是编辑目标。必须延续 Image 1 的透明玻璃小瓶、淡米白饮品、温暖深棕描边和略俯视的正面视角。

主体设计：保留单只圆肩、收腰、宽瓶口的透明玻璃小瓶。将试作品的瓶身比例修整得更匀称，瓶口玻璃厚度更统一，轮廓更干净。瓶内是细腻的淡象牙色米浆，只加入一条清楚、克制的奶白旋涡；玻璃边缘有少量浅青灰反光，底部有一圈很薄的暖米色折射。整体看起来制作稳定、口感顺滑，但仍然朴素，不出现豪华装饰，为后续两档保留明显升级空间。

画风：与 Image 1 高度一致的 2D 卡通游戏食物图标；半手绘质感；清晰的深可可棕外轮廓；温暖明亮配色；柔和分层的赛璐璐与轻厚涂混合上色；圆润高光；简化但可口的材质。不要写实摄影，不要 3D 渲染。

构图与尺寸：严格输出 512×512 px 透明 PNG。主体精确占用连续的竖向 `2×1` 格（2 行×1 列），保持高而窄的瓶身；不得画成 `2×2` 近方形，未占用区域完全透明。单一主体居中，完整显示瓶口和瓶底。

原料规则：米、泉水和糖可以作为克制的画面辅助元素：仅在瓶身下方放 1–2 粒圆润白米、2 粒半透明糖晶和一小段弧形清水波纹。所有原料均小于瓶身宽度的四分之一，不遮挡瓶口、瓶身或主旋涡。

进阶视觉：稳定款只使用奶白、浅米金和少量青灰 3 种主色；瓶颈增加一圈极细暖金玻璃环，配合上述微小米粒、水纹和糖晶，作为唯一一组轻量装饰。不要出现任何文字。

背景与限制：输出带 alpha 通道的透明 PNG，四角必须完全透明；禁止绿色、白色、黑色或任何纯色背景。不要桌面、地面、场景、投影、外发光、粒子。不要文字、数字、Logo、水印、边框、徽章、星星、皇冠、丝带。不要吸管、勺子、托盘、额外杯子或第二瓶饮品。不要过度复杂、过度华丽或达到最高档强度。
```

### 人气款

```text

进阶视觉：第二进阶档使用象牙白、奶油、烘焙米金、青灰和珊瑚红 5 种主色；在瓶颈加入细暖金环、瓶身加入抽象流线压纹，并用珊瑚红小水滴、米金糖晶和白米半环构成两组紧凑装饰。瓶形与旋涡比稳定款更饱满、更有流动感，但不使用旗帜、吊牌或文字。

背景与限制：输出带 alpha 通道的透明 PNG，四角必须完全透明；禁止绿色、白色、黑色或任何纯色背景。不要桌面、场景、投影、外发光、粒子或漂浮装饰。不要文字、数字、Logo、水印、边框、徽章、星星、皇冠、旗帜、吊牌或丝带。不要吸管、勺子、托盘、第二个容器。不要使用金属宝石或极繁装饰，避免提前消耗最高档的视觉空间。
```

### 招牌款

```text
任务：为游戏配方“米浆饮”生成全新的最高进阶档图标，这是该配方视觉进阶的最高档。

输入图片：Image 1 是同一配方的试作品图标，仅作为配方身份和画风参考，不是编辑目标。保留透明玻璃瓶米浆这一核心身份、Image 1 的暖棕描边和卡通手绘渲染，但让造型具有独一无二、可作为店铺代表物的完成度。

主体设计：设计一只具有标志性 S 曲线轮廓的手作玻璃米浆瓶：双层卷边瓶口、柔和圆肩、轻微收腰、稳定厚实的弧形瓶底，整体仍然可爱圆润。瓶身玻璃由平滑面与少量宽切面组成，形成清楚而不过分写实的浅青灰与暖琥珀折射。瓶内呈现三层连贯的大理石式米浆旋涡：明亮象牙白、柔奶油色、浅烘焙米金色，从瓶口旋入瓶身并形成醒目的 S 形主纹理。瓶身加入一条与旋涡呼应的抽象流线压纹，不能画成具体原料。高光、透明感、液体层次和轮廓设计都达到最高完成度，但主体仍清爽、易读。

画风：与 Image 1 同系列的高完成度 2D 卡通游戏食物图标；深可可棕清晰描边；温暖高饱和但协调的配色；半手绘质感；精致的赛璐璐与轻厚涂混合明暗；圆润、干净、可口。不是写实照片，不是 3D 渲染，不要改变成其他游戏画风。

构图与尺寸：严格输出 512×512 px 透明 PNG。主体精确占用连续的竖向 `2×1` 格（2 行×1 列），保持高而窄的 S 曲线瓶身；不得画成 `2×2` 近方形，未占用区域完全透明。略俯视正面视角，瓶口、旋涡和瓶身构成清晰主视觉。

原料规则：可见原料可用 3–5 粒圆润白米、少量糖晶、两段小型清水波纹和一枚珊瑚红米浆水滴，组成贴合瓶底与瓶侧的环绕式配料装饰；它们必须清晰可辨但小于主体，不得遮挡 S 形瓶身或主旋涡。

进阶视觉：最高进阶档使用象牙白、奶油、米金、浅琥珀、青灰和朱红 6 种主色；增加双层瓶口暖金环、瓶身抽象流线压纹、底部小琥珀玻璃坠饰，并以朱红水滴、米金糖晶、白米半环和清水双弧构成至少三组紧凑配料装饰。S 形瓶身、三层旋涡和原料环绕均比前两档更夸张、更饱满，但绝不使用文字或旗帜。

背景与限制：输出带 alpha 通道的透明 PNG，四角必须完全透明；禁止绿色、白色、黑色或任何纯色背景。不要桌面、场景、投影、外发光、光环、粒子或闪粉。不要文字、数字、Logo、水印、边框、徽章、星星、皇冠、旗帜、吊牌或丝带。不要吸管、勺子、托盘、第二瓶饮品。高级感必须来自瓶型、玻璃折射、米浆纹理和配料装饰的共同设计。
```
