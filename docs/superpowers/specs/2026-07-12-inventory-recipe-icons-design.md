# 库存配方图标设计

## 目标

库存页面的配方成品格与原料格统一为 `80×80`。配方成品格显示库存专用配方图标，图标由原始 `512×512` 源图整体等比高质量缩小为 `80×80`，所有配方使用完全相同的缩放比例。

## 资源规则

- 源目录：`../output/imagegen/`。
- 目标目录：`res://resources/recipe_icons_inventory/`。
- 仅处理 `scripts/catalog.gd` 中 `RECIPES` 定义的 149 个配方。
- 每张源图必须为 `512×512`，完整画布使用 Pillow LANCZOS 缩放至 `80×80`。
- 不按透明像素边界裁剪，不拉伸，不使用橱窗的多格变体图。
- 输出名称统一为 `<recipe_id>.png`，不修改源图。

## 库存格显示

- 配方成品格：`80×80` 按钮，内部 `RecipeIcon` 铺满 `80×80`，右下角显示数量角标。
- 原料格：保持现有名称、数量和来源入口行为，仅把单格统一为 `80×80`。
- 配方成品格继续支持左键选择、右键选择橱窗变体、拖拽到橱窗以及现有 tooltip。
- 配方名称、来源、变体和形状信息继续由 tooltip 提供，避免覆盖图标。

## 网格密度

- 保持 10 列、每页 80 格，即 8 行。
- 格间距保持 4 像素。
- 若运行时布局检查发现横向溢出，再只调整库存主面板与侧栏比例，不改变 `80×80` 单格硬约束。

## 验证

- Python 测试证明源图未修改、输出为 RGBA `80×80`、透明边界按相同几何比例保留、缺失或非 `512×512` 源图会阻止发布。
- Godot 聚焦自检证明配方格和原料格均为 `80×80`，配方格加载库存专用图标并保留拖拽数据、右键行为和数量角标。
- 运行库存相关聚焦测试与 MVP 自检，并区分既有无关失败。
