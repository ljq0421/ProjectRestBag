# 橱窗天气预报与经营倒计时图标设计

## 目标

将橱窗经营顶部栏中的常驻环境文字与倒计时数字替换为两个紧凑图标，减少顶部栏文字占用，同时通过悬停提示保留完整经营信息。

## 范围

- 仅修改 `project-rest-new` 的橱窗经营顶部栏。
- 保留现有经营阶段、热度条、规则按钮和开始营业按钮。
- 不修改天气生成、经营轮次时长、结算或热点规则。

## 天气预报图标

- 顶部栏只显示一个 30×30 的天气图标，不常驻显示环境文字。
- 图标根据当前轮次 `environment.weather.id` 切换：
  - `clear_day`：晴朗图标。
  - `light_rain`：小雨图标。
  - `warm_day`：暖日图标。
- 未识别或缺失的天气 ID 使用通用天气预报图标，不能显示空白。
- 悬停提示沿用完整环境状态，包含环境组合名称、售价修正、售速修正与热点。

## 经营倒计时图标

- 顶部栏只显示一个 30×30 的闹钟图标，不常驻显示秒数。
- 闹钟外框与铃铛保持静止，只有钟面秒针运动。
- 标准 30 秒经营轮次开始时，秒针从钟面 `12/0` 位置出发；随着剩余时间减少顺时针连续旋转一整圈；剩余时间为 0 时回到 `12/0`。
- 指针角度直接由当前轮次的 `remaining_ms` 与轮次总时长计算，不使用独立补间计时，避免暂停、掉帧或状态刷新后产生漂移。
- 调整阶段显示 30 秒起始位置；营业阶段随真实剩余毫秒连续更新；待结算阶段固定显示 0 秒结束位置。
- 悬停提示使用 `经营倒计时：%.1f 秒`，并随剩余时间更新。

## 场景与资源结构

- 稳定 UI 结构放在 `showcase_board.tscn`：天气图标、闹钟外框与秒针节点均由场景声明。
- 使用轻量 SVG 图标资源，以便在 Godot 中保持清晰缩放并延续现有甜品店配色。
- `main_view.gd` 只负责根据轮次状态切换天气纹理、更新两个提示文本以及设置秒针角度。
- 保留现有节点语义或同步更新所有直接引用，避免运行时路径和教程定位失效。

## 验证

- 场景自检确认天气与倒计时已改为图标节点，且常驻文本为空。
- 自检分别注入晴朗、小雨、暖日，确认天气纹理切换。
- 自检验证剩余 30、22.5、15、7.5、0 秒时秒针分别位于 0°、90°、180°、270°、360°等价位置。
- 自检验证天气提示包含完整环境信息，倒计时提示包含一位小数秒数。
- 运行现有橱窗经营轮次自检，确认开始、运行、归零、结算和下一轮重置行为未回归。

## 非目标

- 不为天气图标增加动画。
- 不改变经营轮次默认 30 秒时长。
- 不在图标旁保留天气名称、经营修正或倒计时数字。
- 不为图标增加点击行为。
