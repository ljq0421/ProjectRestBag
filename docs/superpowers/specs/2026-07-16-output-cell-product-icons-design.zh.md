# 产出页生产格实际产物图标设计

## 背景

`产出`页面的生产格当前主要用按钮文字描述投入物、剩余时间和状态。对于会收获多种实际产物的生产项，例如小鸡仔会收获鸡蛋和鸡肉，文字既占据格子空间，也不能直观表达本轮真正可获得的内容。

本次调整同时应用于 `project-rest` 和 `project-rest-new`。两套项目保持相同的视觉规格，但各自保留现有拖拽、收获、托管和翻页行为。

## 已确认方案

### 格子与展示区域

- 生产格运行时尺寸保持 `112×112`，不调整产地板块或生产格排布。
- 格子内部使用固定 `112×96` 产物展示区域，居中放置；横向占满 `112×112` 生产格。产物图片本身已有左右透明留白，因此不额外预留格内横向边距。
- 顶部保留现有生产进度条；格子内不再显示倒计时、“剩余时间”、“生产中”或“可收获”等状态文字。
- 进度完成时只通过进度条填满表达，不额外增加完成状态文案。

### 单产物

- 单产物图标在 `112×96` 展示区域内居中，位置为 `(10, 2)`。
- 图标最大显示尺寸为 `92×92`，保持原图宽高比，不拉伸变形。
- 数量继续使用右下角角标显示。

### 双产物

- 当前生产配置最多只有两种实际收获产物，没有三种及以上产物的生产项。
- 两个产物图标均为 `60×60`。
- 两图标在 `112×96` 展示区域内错位重叠：第一个位于 `(0, 8)`，第二个位于 `(52, 28)`，水平方向的等效重叠量为 `8px`。
- 两个图标分别保留自己的数量角标，不能合并成总数量。
- 图标顺序使用实际收获产物字典的稳定顺序；前一个位于底层，后一个位于上层。

## 数据与渲染

生产格展示的是实际收获产物，不是投入生产的原始条目。活动生产格使用：

```gdscript
ProductionSite.harvest_outputs_for(site_id, item_id)
```

返回结果中的键是产物 ID，值是本轮产量。例如：

- `chick`：鸡蛋 `×2`、鸡肉 `×1`
- `calf`：牛奶 `×2`、牛肉 `×1`
- `duckling`：鸭蛋 `×2`、鸭肉 `×1`
- `lamb`：羊奶 `×2`、羊肉 `×1`

单产物生产项沿用同一数据入口，只渲染一个图标。图标纹理复用现有食材图标加载路径和缺失资源回退机制，不新增同义资源目录。

如果未来数据出现三种及以上实际产物，界面显示前两个产物并增加 `+N` 溢出角标，同时在提示文本中列出完整产物，避免静默丢失信息；当前数据不会进入该分支。

## 场景与脚本边界

稳定布局放在 `scenes/ui/pages/output_cell.tscn`：

- `ProductDisplayArea`：固定产物展示区域。
- 单产物图标层。
- 双产物主、副图标层。
- 各自数量角标。
- 现有 `ProductionProgressBar` 保留在顶部。

`scripts/output_cell.gd` 负责接收产物纹理与数量、切换单产物或双产物布局、清空旧状态和生成完整提示文本。`scripts/main_view.gd` 只负责从生产状态读取实际产物、加载纹理并调用生产格的绑定接口，不在主页面脚本中拼装稳定节点。

空闲格、待解锁格和产物背包格继续使用原有文字及交互；本次图标布局只应用于已有生产任务的活动生产格。

## 行为保持

- 点击已完成生产格仍执行现有收获流程。
- 拖拽开始、拖回背包、投放目标和右键交互保持不变。
- 托管状态与暂停原因不再占用格子内部可见文字区域，但仍可通过现有产地板块状态和提示文本获得。
- 生产进度刷新只更新进度条，不反复创建图标节点或重新加载纹理。
- 页面翻页、八个生产格和四个产地板块布局不变。

## 异常与回退

- 实际产物字典为空时，回退到当前投入物的图标与单产物布局，避免活动格空白。
- 某个产物图标缺失时，使用现有缺图回退视觉，并在提示文本中保留产物名称和数量。
- 非正数产量不创建可见产物图标。
- 刷新生产格前必须清空上一次绑定的纹理、角标、溢出标记和提示文本，避免翻页或收获后残留。

## 验证标准

两个项目分别增加或扩展聚焦自检，覆盖：

1. 生产格运行时仍为 `112×112`，展示区域为 `112×96`。
2. 单产物使用一个最大 `92×92` 的居中图标并显示独立数量角标。
3. 小鸡仔、小牛犊、小鸭苗和小羊羔均显示两个 `60×60` 的实际产物图标，使用 `(0, 8)` / `(52, 28)` 位置形成 `8px` 水平重叠，且数量正确。
4. 活动生产格不再显示投入物名称、倒计时、“生产中”或“可收获”文字。
5. 生产中进度条按比例更新；生产完成时进度条填满。
6. 点击收获、拖拽、翻页和托管路径的现有聚焦自检继续通过。
7. 缺失产物图标和空产物字典不会造成报错或空白活动格。

## 不在本次范围

- 不修改生产时间、产量、价格或解锁规则。
- 不修改产出总览、产地图片、翻页器或产物背包格布局。
- 不增加新的三产物生产配置。
- 不调整 `112×112` 生产格尺寸。
