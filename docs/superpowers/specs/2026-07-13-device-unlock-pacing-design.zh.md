# 无限店铺等级与单级单设备升级设计

## 1. 目标

店铺采用持续经营结构，不设置结局、通关等级或最高等级：

- 店铺等级数字可以无限增长。
- Lv.0–Lv.5 是基础厨房建设期，每级只开放一台基础设备。
- Lv.6 以后是持续经营期，升级条件由统一公式生成。
- 升级消耗金币；口碑是累计经营资历，只检查、不扣除。
- Lv.6 以后平均每级需要 5–7 个标准营业日，并随等级逐步提高。
- 配方研发、指定商品、任务、评鉴和门店评级都不作为普通升级硬门槛。

Lv.5 只表示六类基础设备全部集齐，不表示 MVP 完成、通关或经营结束。

## 2. 基础设备路线

| 等级 | 新开放设备 | 阶段定位 |
|---:|---|---|
| Lv.0 | 蒸煮一体的圆锅 | 完成第一份可售商品 |
| Lv.1 | 研磨机 | 学习原料加工与正式营业 |
| Lv.2 | 烤箱 | 建立基础烘焙路线 |
| Lv.3 | 冷藏柜 | 学习冷藏商品、临期与库存规划 |
| Lv.4 | 煎烤盘 | 扩展多设备菜单与高客流经营 |
| Lv.5 | 搅拌机 | 开放复合配方、精加工与招牌甜品 |

设备开放等级是设备可用性的统一来源。普通任务不再提前奖励后续等级设备。

### 2.1 食材与配方分级口径

- “核心食材”指可以直接参与烹饪或加工配方的食材。种子、幼畜、泉水引等生产投入品不计入核心食材数量，但必须与对应产物在同一级开放。
- “售卖配方”指能够制作成商品并上架销售的配方。研磨、发酵等加工配方不计入各级售卖配方数量。
- Lv.0 只有 3 种核心食材是教学期例外；Lv.1–Lv.5 每级新增 6–10 种核心食材。
- 各级售卖配方数量采用高密度递增曲线，必须严格满足 `1 < 8 < 17 < 23 < 35 < 44`。
- 任一配方的解锁等级不得早于其所需设备、全部核心食材和全部加工产物的解锁等级。
- 现有 149 道配方只允许调整解锁等级，不修改 ID、名称、设备、材料、售价、产量或标签；新增养殖产物通过全新配方承接。

## 4. Lv.6+ 完整升级公式

### 4.1 变量

对任意目标等级 `L >= 6`：

```text
n = L - 6
s = floor(n / 5)
D(L) = min(7.0, 5.0 + 0.5 * s)
```

`D(L)` 是数值平衡目标，不是硬性营业日门槛：

| 目标等级 | D(L) |
|---:|---:|
| Lv.6–Lv.10 | 5.0 个标准营业日 |
| Lv.11–Lv.15 | 5.5 个标准营业日 |
| Lv.16–Lv.20 | 6.0 个标准营业日 |
| Lv.21–Lv.25 | 6.5 个标准营业日 |
| Lv.26+ | 7.0 个标准营业日 |

### 4.2 金币要求

Lv.5 的标准营业日经济基线取：

```text
标准金币收入 = 600 / 营业日
```

目标等级的金币费用：

```text
C(L) = round_to_100(
    3000 * (D(L) / 5.0) * (1.0 + 0.08 * n)
)
```

`round_to_100` 表示四舍五入到最接近的 100 金币。升级成功时扣除 `C(L)`。

该公式让目标经营周期从 5 天逐渐提高到 7 天，同时让绝对金币费用持续增长。增长使用线性经营基线乘分段周期，不使用指数曲线。

### 4.3 累计口碑要求

Lv.5 的标准营业日口碑基线取：

```text
标准口碑收入 = 45 / 营业日
R(5) = 85
```

每个目标等级新增的累计口碑要求：

```text
DeltaR(L) = round_to_5(
    225 * (D(L) / 5.0) * (1.0 + 0.05 * n)
)

R(L) = R(L - 1) + DeltaR(L)
```

`round_to_5` 表示四舍五入到最接近的 5 口碑。升级只检查当前累计口碑是否达到 `R(L)`，不扣除任何口碑。

运行时可以缓存已经计算过的 `R(L)`；公式适用于任意正整数等级，不依赖有限升级表。

### 4.4 升级判定

对 `L = 当前等级 + 1`：

```text
可以升级 = 当前金币 >= C(L)
        且 当前累计口碑 >= R(L)
```

升级成功：

```text
金币 -= C(L)
口碑保持不变
店铺等级 = L
```

每次操作只提升一级。即使玩家储蓄足够，也需要逐级确认，确保每一级通知、里程碑和存档写入都能按顺序发生。

不增加以下条件：

- 强制营业日数量；
- 指定配方研发；
- 指定设备销售；
- 主线或可选任务完成状态；
- 美食家评鉴分数；
- 门店评级或称号。

## 6. 无限等级与内容里程碑

店铺等级无限增长，不等于每一级都必须增加一项永久能力。

- 基础设备只在 Lv.0–Lv.5 开放。
- Lv.6 以后允许通过独立的 `LEVEL_MILESTONES` 配置追加扩建、主题、客群、自动化容量、外观或评鉴内容。
- 没有配置里程碑的等级仍可升级，表示经营资历，并推进到下一个可见里程碑。
- 里程碑奖励不能无限叠加生产倍率、顾客数量、橱窗容量或自动化容量。
- 新版本可以向任意更高等级追加里程碑，不需要修改等级公式或迁移既有等级。

营业手册同时展示：

1. 下一等级的金币与累计口碑要求；
2. 当前分别还差多少；
3. 升级按钮；
4. 下一个已配置里程碑及其等级；
5. Lv.6+ 的预计平衡周期为 5–7 个标准营业日。

## 7. 配方与任务重排

所有配方和加工配方必须满足：

```text
配方解锁等级 >= 所需设备解锁等级
配方解锁等级 >= 所有原料与加工产物解锁等级
```

第 2.2–2.8 节是 Lv.0–Lv.5 食材、加工配方、售卖配方和 Lv.6+ 配方储备池的唯一目标清单。实施时必须按该清单重排数据，不能只把旧配方整体顺延一级。

实施同步要求：

- `rice_flour_process` 调整到 Lv.1，由研磨机制作大米粉。
- 新增或校正小麦制面粉、糯米制糯米粉、咖啡制可可粉、牛奶加酵母制酸奶、绿茶制抹茶的加工关系。
- 现有配方只调整必要的 `unlock_level`；包括 `banana_baked_pancake` 在内的现有配方不得改 ID、名称、设备、材料、售价、产量或标签。
- 新增蜜蜂群、小鸭苗和小羊羔三种养殖投入品，以及鸭蛋、鸭肉、羊奶、羊肉四种新核心食材；蜂蜜由林场产出改为蜜蜂群养殖产出。
- Lv.0–Lv.5 新增核心食材数必须为 `3 / 6 / 10 / 10 / 10 / 10`，售卖配方数必须为 `1 / 8 / 17 / 23 / 35 / 44`。
- 128 道售卖配方进入 Lv.0–Lv.5；38 道现有配方进入 Lv.6+ 储备池，全游戏合计 166 道售卖配方。
- 本轮新增的 17 个配方 ID 必须与第 2.3、2.5、2.6、2.7 节完全一致，不能通过改造旧配方代替。
- 种子、幼畜和泉水引与对应产物同级开放，但不计入核心食材数量；加工配方不计入售卖配方数量。

任务路线同步遵循：

- Lv.0 的“第一份商品”不再提前奖励研磨机；研磨机随 Lv.1 开放。
- Lv.1 的营业与顾客教学可以保留。
- Lv.2 改为烤箱阶段教学。
- Lv.3 改为冷藏柜、临期和库存阶段教学。
- Lv.4 改为煎烤盘与多设备菜单阶段教学。
- Lv.5 改为搅拌机、复合配方和招牌阶段教学。
- Lv.1–Lv.5 的升级准备任务不再通过 `set_level` 自动升级；它们只显示进度、奖励和“可以升级”提示。

配方任务继续是可选内容，不能阻止升级。

## 8. 运行结构

升级规则由一个运行时入口统一提供，例如：

```text
Catalog.get_upgrade_definition(target_level)
```

- Lv.0–Lv.5 返回显式配置。
- Lv.6+ 返回公式生成的费用、累计口碑、阶段名和已配置里程碑。
- `GameState.can_upgrade()` 只读取该入口。
- `GameState.upgrade()` 只扣金币，不扣口碑，并逐级升级。
- 存档加载不再用有限升级表的最大键值裁剪等级。
- 任务系统不再是 Lv.1 以后改变店铺等级的所有者。

升级按钮放在现有营业手册的“阶段路线”区域，稳定结构写在 `.tscn`，脚本只负责绑定要求、缺口、禁用原因和升级信号。

升级失败必须给出可见原因：

- 金币不足：显示缺少金币数量；
- 累计口碑不足：显示缺少口碑数量；
- 两者都不足：同时显示两个缺口；
- 升级成功：显示新等级、新设备或里程碑，以及下一等级要求。

## 11. 验证

至少覆盖以下自动化检查：

1. Lv.0–Lv.5 每级恰好新增一台指定基础设备。
2. Lv.0 到 Lv.1 仍由第一次上架教学自动触发。
3. Lv.2–Lv.5 只检查金币和累计口碑。
4. Lv.6、10、11、16、21、26、40、50、75、100 的公式结果与本文表格一致。
5. 金币费用、本级新增口碑和累计口碑在无限抽样范围内保持单调增长。
6. 升级只扣金币，口碑升级前后完全相等。
7. 余额或口碑不足时等级和资源不改变，并返回明确缺口。
8. 单次操作只提升一级。
9. 高于 Lv.5 的等级可保存、加载且不被裁剪。
10. 新规则创建的存档可正常保存和加载；不测试旧开发存档迁移。
11. 所有配方的解锁等级不低于所需设备等级。
12. 所有配方的解锁等级不低于全部原料和加工产物等级。
13. Lv.0–Lv.5 新增核心食材数量严格等于 `3 / 6 / 10 / 10 / 10 / 10`。
14. Lv.0–Lv.5 新增售卖配方数量严格等于 `1 / 8 / 17 / 23 / 35 / 44`，合计 128 道且无重复、无遗漏。
15. Lv.6+ 储备池恰好包含另外 38 道现有售卖配方，全游戏合计 166 道售卖配方。
16. 17 道新增配方的 ID、名称、设备和材料与第 2 节一致，且每种新增养殖产物至少被两道新增配方使用。
17. 现有 149 道配方除解锁等级外的字段与实施前完全一致。
18. 小鸡仔、小牛犊、蜜蜂群、小鸭苗、小羊羔分别在 Lv.1–Lv.5 开放，并产出本文指定食材。
19. 除 Lv.0 第一次上架外，任务奖励不再包含 `set_level`。
20. 升级 UI 显示下一等级要求、资源缺口和下一个里程碑。
21. 全仓库不再把 Lv.5、名店评级或长期经营挑战描述为结局。

优先运行升级公式、设备路线、食材与配方数量的专用自检，再运行任务、营业手册、新存档保存加载和 `mvp_self_check.gd`。Godot 无头测试必须按项目 `AGENTS.md` 指定可写的 `--log-file`。
