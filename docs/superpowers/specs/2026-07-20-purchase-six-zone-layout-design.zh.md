# 采购页六区平铺设计

日期：2026-07-20  
目标项目：`D:\Project\ProjectRest\project-rest-new`

## 背景

当前采购页通过六个来源 tab 在同一个滚动列表中切换商品，来源依次包含农场、养殖场、林场、水塘、辅料和工具。玩家无法同时比较不同来源的商品，切换 tab 也增加了连续补货的操作成本。

本次把六个 tab 改为同页可见的六个固定区域，同时保留现有商品可见性、购物车、整单购买、小票、任务和存档语义。

## 目标

- 在采购页中以三列、两行平铺六个采购区域。
- 六区顺序固定为：
  - 第一行：农场、养殖场、林场。
  - 第二行：水塘、辅料、工具。
- 六个区域等高，每个区域独立纵向滚动。
- 六个区域共用页面底部的购物车汇总和购买按钮。
- 商品行中的单价和库存只显示语义图标与数值，不显示“金币”“库存”文字。
- 保持现有采购规则、购物车结算、小票、任务进度、存档和教程路径。

## 非目标

- 不改变商品价格、来源、解锁等级或可采购条件。
- 不改变工具购买和普通原料购买的业务规则。
- 不重新设计采购小票或其他页面。
- 不新增采购筛选、搜索、折叠、展开或排序功能。
- 不同步修改 `project-rest` checkout。

## 页面结构

`purchase_page.tscn` 保留顶部说明和底部购物车区域。中间的 `PurchaseCategoryTabs`、单一 `PurchaseItemsScroll` 和隐藏数据中转列表由三列 `GridContainer` 取代。

网格中放置六个同类型采购区域实例：

```text
农场      养殖场      林场
水塘      辅料        工具
```

每个区域由以下节点组成：

- 区域标题。
- 固定高度的 `PanelContainer`。
- 独立的 `ScrollContainer`。
- 承载商品行的 `VBoxContainer`。
- 无商品时的紧凑空状态。

网格占用采购页中部剩余空间，两排平均分配高度。购物车汇总和购买按钮位于网格外，因此不会随任何区域滚动。

## 可复用组件

新增采购区域场景和脚本。区域组件只负责：

- 保存区域标识和标题。
- 接收并展示属于该区域的商品行。
- 展示或隐藏空状态。
- 发出商品数量变化信号。
- 暴露按 `item_key` 查找商品行和教程目标的方法。
- 在内容刷新前后保存并恢复自己的纵向滚动位置。

区域组件不直接修改金币、库存、购物车或存档。所有业务状态仍由 `main_view.gd` 和现有服务处理。

## 商品行

商品行保持单行紧凑布局：

```text
商品名 | 金币图标 数值 | 库存图标 数值 | - 数量 +
```

- 商品名占用可伸缩空间；空间不足时截断，不允许撑宽区域。
- 商品名提供完整文本的悬停提示。
- 金币和库存使用两个小型 SVG 图标，避免依赖系统 Emoji 字体回退。
- 金币图标悬停提示为“单价”，库存图标悬停提示为“当前库存”。
- 可见商品行不出现“金币”“库存”文字。
- 两种图标尺寸、对齐和视觉重量保持一致。

## 数据流

采购页刷新时，`main_view.gd` 按固定区域顺序遍历六个来源，并继续调用现有候选商品和解锁判断逻辑。每个可见商品被配置为对应区域内的商品行。

购物车继续使用现有 `purchase_cart_quantities` 字典，并以 `item_key` 作为唯一键。区域组件发出数量变化后，`main_view.gd`：

1. 验证商品仍可采购和购物车总价未超过金币余额。
2. 更新 `purchase_cart_quantities[item_key]`。
3. 更新页面中所有具有同一 `item_key` 的商品行。
4. 更新底部购物车汇总和购买按钮状态。
5. 延迟刷新教程指引目标。

同一商品可能同时存在于多个来源，例如农场和林场。重复来源行共享一个购物车数量；任意一行发生变化时，其他同键行的数量和按钮状态同步更新。

点击底部购买按钮后，继续沿用现有整单校验、扣款、入库、小票、任务推进、存档和购物车清零流程。

## 刷新与滚动

- 普通 `+` 或 `-` 操作只更新相关行和汇总，不重建六区，避免滚动位置跳回顶部。
- 购买完成、等级或解锁状态变化等需要改变商品集合的事件可以刷新区域内容。
- 区域内容刷新前记录各自的纵向滚动值，刷新后恢复；若原值超过新范围，由 `ScrollContainer` 自动限制到有效范围。
- 某一区域没有可采购商品时，该区域保留并显示空状态，不改变网格位置。

## 教程兼容

旧教程会先切换到农场 tab，再寻找 `rice_seed` 行。六区平铺后取消分类选择状态，并改为：

1. 在农场区域查找 `rice_seed` 商品行。
2. 让农场区域滚动到该行可见。
3. 当购物车中尚无 `rice_seed` 时，将教程目标设为该行的 `+` 按钮。
4. 当购物车已有 `rice_seed` 时，将教程目标设为底部购买按钮。

购买水稻种子后，教程仍通过真实采购完成事件进入产出步骤；跳过教程不发放采购奖励。

## 异常与反馈

- 金币不足时，`+` 按钮禁用或拒绝增加，并继续通过状态栏说明原因。
- 商品在操作前失效时，不修改购物车或库存，并显示明确原因。
- 整单结算失败时不允许部分扣款，不清空购物车，也不展示成功小票。
- 重复来源行必须同步数量、库存和按钮禁用状态。
- 图标导入失败、节点缺失或区域顺序错误应由聚焦自检直接失败，不静默降级为文字标签。

## 验收标准

- 采购页不存在分类 tab，六区按指定顺序以三列、两行显示。
- 六区等高并各自拥有独立纵向滚动容器。
- 底部购物车和购买按钮不属于任何区域的滚动内容。
- 商品行中不显示“金币”“库存”文字；对应 SVG 图标和数值可见，图标具有悬停说明。
- 长商品名不会扩大区域宽度，并可通过悬停查看完整名称。
- 修改任意商品数量不会重置各区滚动位置。
- 同一 `item_key` 的重复来源行保持数量和按钮状态同步。
- 整单购买、小票、任务推进和教程采购路径继续正常工作。
