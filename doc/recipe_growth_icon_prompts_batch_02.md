# 第 6–15 个配方进阶图标 ImageGen 提示词（project-rest-new，v1）

> **当前状态（2026-07-22）：** 稳定款已从游戏删除。本文中的稳定款段落仅作历史记录，不再生成或交付；当前有效范围只有人气款与招牌款。

## 使用方式

- 每次将下方的“通用基础提示词”与一个对应档位的“专属提示词”一起复制给 ImageGen，并上传同配方的试作品 PNG 作为 `Image 1`。`Image 1` 只用于身份、画风、视角、描边和材质参考，不是编辑目标。
- 本批次以 `project-rest-new/scripts/catalog.gd` 的原材料和 `doc/recipe_display_config.json` 的布局为准。稳定款、第二进阶档继承试作品布局；最高进阶档仅使用配置中明示的覆写布局。
- 画布规则：`1×1`、`1×2`、`2×1`、`2×2` 一律为 **512×512 px**；任一边为 3 格的 `2×3` 一律为 **768×768 px**。所有未占用格必须完全透明。
- “稳定款 / 人气款 / 招牌款”仅是文档档位名。可复制提示词中不使用这些字样，且生成图标中不得出现任何文字。

## 通用基础提示词（与每个专属提示词一起使用）

```text
Use case: stylized-concept。Asset type: 2D 卡通经营游戏中的配方图标。
输入图片：Image 1 是同配方试作品，只作为配方身份、略俯视正面视角、深可可棕描边、半手绘赛璐璐加轻厚涂材质的参考；生成全新的进阶图标，不要直接编辑 Image 1。必须保持同系列温暖、圆润、可口、非写实的画风，不要照片感、3D 渲染或改变为其他画风。
透明要求：输出指定像素尺寸、带 alpha 通道的透明 PNG；画布四角及未占用格完全透明。禁止绿色、白色、黑色或任何纯色背景，禁止桌面、地面、场景、投影、外发光、光环、粒子和闪粉。
文字限制：不要文字、数字、字母、Logo、水印、边框、徽章、旗帜、吊牌、皇冠、星星或丝带。
原料限制：原材料只作为贴近主体的小型辅助装饰，不得遮挡主体、变成第二份主食或散落成背景；不要加入配方表以外的水果、酱汁、奶油、巧克力或餐具。
```
