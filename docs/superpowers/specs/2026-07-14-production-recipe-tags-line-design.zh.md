# 制作成品标签行设计

## 范围

- 只修改 `project-rest-new`。
- `project-rest` 已有成品扩展信息，保持不变。
- 只影响“研发制作”页面右侧制作列表中的成品行，不影响中间产品行。

## 展示规则

- 在成品名称与材料信息所在主行下方增加一行常驻文本。
- 文本格式为 `标签：标签1、标签2`，数据直接读取 `scripts/catalog.gd` 中配方的 `tags`。
- 标签为空时显示 `标签：暂无`。
- 该行只展示标签，不展示今日需求、匹配顾客、仓库数量、橱窗数量或可制作批次。
- 不把口味标签追加到悬停提示中。

## 结构与验证

- 在 `recipe_action_row.tscn` 中使用 `RecipeInfoColumn` 包含原有 `RecipeInfo` 和新的 `RecipeTagsLabel`。
- `recipe_action_row.gd` 负责绑定配方标签并在中间产品行隐藏标签节点。
- 聚焦测试验证米浆饮显示 `标签：经典、清爽`、标签行没有其他经营信息、原有名称悬停提示不包含标签。
