# 库存格中文名称显示设计

## 目标

库存弹窗中的每个非空格子显示物品中文名称与数量，不再在格子内部显示“采购”“农场”“养殖场”等来源文字。

## 显示规则

- 食材和成品继续显示现有图标，并在格子底部增加中文名称标签；数量角标保持不变。
- 没有专用图标的物品继续使用文字格，正文为“中文名称 + 数量”。
- 删除格子内部的来源按钮，避免来源文字挤占名称区域。
- 来源信息仍保留在鼠标提示和库存搜索数据中，不改变信息查询能力。

## 交互边界

- 格子点击选择、成品拖拽上架和右键选择变体保持不变。
- 库存面板底部的一键补货继续作为补货入口。
- 本次不修改采购页、农场等产地页面，也不修改库存数据结构。

## 验收与测试

- 食材格、成品格均能在格子中找到对应中文名称。
- 格子中不存在带来源动作元数据的子按钮，也不显示“采购”“农场”“养殖场”等来源文本。
- 数量角标、格子选择和成品拖拽能力仍然存在。
- 使用带可写 `--log-file` 路径的 Godot 4.6.1 headless 自检验证。
