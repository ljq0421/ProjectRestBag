# Lv.0 新手生产线实施计划

> **执行要求：** 直接在 `main` 工作区修改。UI 布局节点写入 `.tscn`，脚本只绑定已有节点、刷新状态和处理交互。

**目标：** 新增 Lv.0 新手引导等级，让玩家通过“水稻种子 -> 水稻 -> 米浆饮 -> 上架售卖”学习后续正式生产线。

**核心设计：** Lv.0 是正式流程的第一段，不是临时流程。采购、农场、研发、生产、上架、橱窗展示在 Lv.0 与后续等级使用同一套机制；生产页提供上架快捷操作，橱窗页始终展示当前上架商品。

## 1. 初始内容

- 初始等级为 Lv.0。
- 采购页默认打开 `农作` tab。
- `农作` 默认解锁 `水稻种子`。
- `工具` 默认解锁 `灵巧的双手`。
- `水产` tab 改名为 `水塘`。
- `水塘` 默认解锁 `泉水`。
- `配料` 默认解锁 `白糖`。
- `农场` 在 Lv.0 解锁，支持种植 `水稻种子`。
- `水稻种子` 只用于种植，收获产物是 `水稻`；研发米浆饮使用 `水稻`，不是 `水稻种子`。

## 2. 任务链

### 任务 1：收获第 1 批水稻

- 完成条件：从农场收获 `水稻` 至少 1 批。
- 奖励：解锁工具 `蒸煮一体的圆锅`。
- 反馈：弹窗提示任务完成和新工具解锁。

### 任务 2：解锁第 1 份食谱

- 完成条件：研发解锁 `米浆饮`。
- 研发组合：`水稻` + `泉水` + `白糖` + 工具 `蒸煮一体的圆锅`。
- 奖励：解锁工具 `研磨机`。
- 反馈：弹窗提示任务完成和新工具解锁。

### 新手完成：米浆饮上架售卖

- 完成条件：制作 `米浆饮` 后在生产页点击上架。
- 结果：自动从 Lv.0 升到 Lv.1，解锁当前原 Lv.1 的正式内容。
- 售卖：生产页上架后立即结算一轮营业；橱窗页仅查看当前在售商品，不提供开始营业或上架操作。
- 反馈：弹窗展示 Lv.1 解锁内容。

## 3. 文件计划

- 修改 `doc/v3.md`：同步 Lv.0 新手线、采购分类、任务奖励、橱窗定位。
- 修改 `scripts/catalog.gd`：新增 `rice_seed`、`rice`、`spring_water`、`rice_milk_drink`、新手工具与 Lv.0 升级表，并让 `sugar` 作为 Lv.0 `白糖`。
- 修改 `scripts/game_state.gd`：初始等级改为 0，增加已解锁工具、已完成任务、待弹窗通知。
- 新建 `scripts/tutorial_progress.gd`：集中处理任务完成、奖励解锁和 Lv.0 自动升 Lv.1。
- 修改 `scripts/production_site.gd`：支持“种子投入，收获另一种产物”。
- 修改 `scripts/recipe_book.gd`：研发成功后触发任务检查。
- 修改 `scripts/main_view.gd`：采购默认 tab、研发材料点击多选、工具单选、生产页上架并立即售卖、橱窗只读展示、任务弹窗显示。
- 修改 `scenes/Main.tscn`：增加任务弹窗节点，保留橱窗页作为上架展示页。
- 修改 `tests/mvp_self_check.gd`：覆盖 Lv.0 初始内容、任务 1/2、米浆饮上架升 Lv.1、生产页上架即售卖、橱窗只读展示。
