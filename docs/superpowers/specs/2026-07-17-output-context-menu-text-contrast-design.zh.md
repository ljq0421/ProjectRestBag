# 产出格子菜单文字对比度修复设计

## 背景

产出页面左键点击正在生产的产出格子时，会弹出可设置的“下轮”种子菜单。该菜单使用奶油色 `DessertPopupMenu` 底图，但普通条目和禁用条目没有针对浅色背景定义文字色，导致文字对比度不足。

## 设计

- 仅修改 `scenes/Main.tscn` 中的 `OutputContextMenu`，不改变全局 `PopupMenu` 或共享的 `DessertPopupMenu` 主题变体。
- 普通文字使用深棕色 `#502611`，与现有甜品主题一致并提高浅底可读性。
- 禁用文字使用较柔和但仍可辨识的棕色；悬停文字沿用现有浅色，以适配悬停选中背景。
- `project-rest` 与 `project-rest-new` 使用同一套颜色契约，避免两份项目在此处产生视觉漂移。

## 验收

- 左键点击正在生产的产出格子，菜单仍列出可设置的下轮种子。
- 普通条目在奶油色背景上呈深棕色，禁用条目仍清晰且能区分状态。
- 右键加速器菜单的交互不受影响。
- 两个项目各自的 `tests/output_quadrant_self_check.gd` 固定上述颜色契约并通过。
