# 外婆 NPC 对话式新手引导设计

## 1. 目标

将现有箭头加短文本的新手引导替换为单一固定 NPC“外婆”主持的对话式引导，同时保留现有十步业务进度、真实操作完成条件、自动路由、动态目标定位和存档兼容逻辑。

新引导采用混合式交互：进入新步骤时主动展开外婆对话；玩家确认后，对话收起为橱窗左下角的外婆图标；玩家继续完成真实操作，步骤推进后再主动展开下一段对话。

本次不新增 NPC 好感、剧情分支、角色养成或正式角色立绘。外婆使用主题化剪影头像，后续可在不改变对话系统契约的情况下替换为正式图片。

## 2. 保留与替换边界

### 2.1 保留

- `TutorialProgress` 的十步顺序和业务完成条件。
- `GameState` 中现有引导步骤、完成状态、跳过状态、收获进度、橱窗移动和旋转进度。
- `main_view.gd` 的引导页面自动路由、动态目标解析和正式弹窗阻塞检测。
- 现有目标箭头及其动态重定位能力。
- “跳过本步”“结束引导”“再来一遍”的业务语义。

### 2.2 替换

- 现有紧贴目标的小型文字提示框。
- 现有居中的完成面板。
- `main_view.gd` 中直接返回引导台词的 `_tutorial_message()` 文案分支。

## 3. 架构与文件职责

### 3.1 `scripts/tutorial_progress.gd`

继续作为引导业务进度的唯一所有者。本次不修改十步顺序和实际完成条件，只补充“重新引导时清空本步骤已读状态”的行为。

### 3.2 `scripts/tutorial_dialogue_catalog.gd`

新增只读对话目录。目录按步骤 ID 返回以下字段：

- `step_name`：玩家可见的步骤名。
- `dialogue`：主动展开时显示的外婆台词。
- `action_hint`：对话收起后，玩家点击外婆图标重新展开时可见的当前行动提示。
- `confirm_label`：收起对话的主按钮文案。

目录不读取或修改游戏状态，不负责推进步骤，也不持有 UI 节点。

### 3.3 `scenes/ui/overlays/tutorial_guide_overlay.tscn`

原场景原地重构，不新增第二套引导 Overlay。稳定结构全部声明在场景文件中：

- `Arrow`：保留现有目标箭头。
- `GrandmaIconButton`：收起状态入口，外框约 `48×48`。
- `DialoguePanel`：展开状态容器，高度约 `118px`。
- `PortraitFrame` 和 `PortraitSilhouette`：暖色主题化外婆剪影，展开头像约 `64px`。
- `SpeakerLabel`：固定显示“外婆”。
- `StepLabel`：显示当前步骤名，不再强调 `1/10` 式系统进度编号。
- `DialogueLabel`：最多显示两行台词。
- `SkipButton`：跳过当前步骤。
- `ConfirmButton`：确认并收起对话。
- `CompletionActions`：仅完成步骤显示“结束引导”和“再来一遍”。

场景文件定义尺寸、层级、主题变体和控件结构；脚本只负责状态切换、信号和动态定位。

### 3.4 `scripts/ui/overlays/tutorial_guide_overlay.gd`

负责：

- 展开、收起、隐藏和完成状态切换。
- 点击外婆图标后重新展开当前对话。
- 根据 `ShowcasePanel` 的全局矩形定位。
- 让展开面板与橱窗区域等宽并贴合橱窗底边。
- 将收起图标固定在橱窗左下角。
- 目标可用时显示箭头，目标不可用时隐藏箭头。
- 正式弹窗阻塞期间临时隐藏，并在解除阻塞后恢复此前展开或收起状态。

### 3.5 `scripts/main_view.gd`

继续承担协调职责：

- 获取当前引导步骤和目标控件。
- 从 `TutorialDialogueCatalog` 读取对话数据。
- 将 `ShowcasePanel` 作为定位区域传给 Overlay。
- 检测步骤变化；新步骤必须触发主动展开。
- 将玩家确认收起后的“本步骤已读”状态保存到 `GameState`。
- 保留原有弹窗阻塞判断、页面自动路由和目标解析。

`main_view.gd` 不再保存具体外婆台词。

## 4. 视觉与布局契约

### 4.1 收起状态

- 仅显示外婆图标，不显示常驻文字提示条。
- 图标位于橱窗区域左下角，外框约 `48×48`。
- 点击图标展开当前步骤对话。
- 图标可用轻量省略号标记提示“可以对话”，不使用持续闪烁或大幅脉冲。
- 目标箭头仍可独立指向当前操作目标。

### 4.2 展开状态

- 对话框与整个橱窗区域等宽。
- 对话框高度约 `118px`，避免大面积遮挡橱窗。
- 对话框贴合橱窗底边，视觉上属于橱窗区域，不漂浮到全屏底部或右侧工作台。
- 左侧为约 `64px` 的主题化外婆剪影，右侧依次为姓名、步骤名、最多两行台词和按钮。
- 展开期间增加轻微遮罩并阻止背景操作；确认收起后恢复游戏操作。
- 完成引导时继续使用同一对话框，不再显示独立居中完成面板。

### 4.3 动态定位

现有橱窗网格的最小尺寸为 `1008×864`。本次不得为了容纳对话框而压缩或重排橱窗格子。Overlay 保持为 `Main` 的独立覆盖层，在运行时读取 `ShowcasePanel.get_global_rect()`：

- 展开宽度等于橱窗矩形宽度。
- 展开位置贴合橱窗矩形底边，并限制在当前视口内。
- 收起图标以橱窗矩形左下角为锚点。
- 分辨率或橱窗尺寸变化时重新计算位置。

## 5. 对话流程

| 步骤 | 主动展开台词 | 收起后的行动提示 | 主按钮 |
| --- | --- | --- | --- |
| 采购 | 新店开张，先别急着做甜品。我们从一袋水稻种子开始，把第一份原料亲手种出来。 | 购买 1 份水稻种子。 | 去买种子吧 |
| 产出 | 很好，种子已经备好了。光靠采购可撑不起一家店，我们去农场把它种下吧。 | 在农场种下水稻种子，成熟后手动收获大米。 | 去农场看看 |
| 研发 | 大米收好了。配上泉水，再用圆锅试一试，我们来研究店里的第一款商品。 | 放入大米和泉水，选择圆锅，研发米浆饮。 | 开始研究吧 |
| 制作 | 米浆饮的做法找到了。记住，知道配方只是开始，做出成品才能摆进橱窗。 | 制作 1 次米浆饮。 | 做一份试试 |
| 上架 | 第一份米浆饮做好了。把它放进橱窗，客人才有机会看见。 | 将米浆饮上架到橱窗。 | 去上架吧 |
| 规则 | 商品已经进橱窗了。摆放位置会影响经营效果，先看看这里的构筑规则。 | 打开“构筑规则”。 | 看看规则 |
| 布局 | 看懂规则后，亲手调整一次吧。把米浆饮拖到新位置，再旋转一次。 | 拖动并右键旋转米浆饮各一次。 | 调整橱窗 |
| 营业 | 橱窗已经准备好了。现在开门营业，看看这套摆法能带来怎样的结果。 | 点击“开始营业”。 | 开门营业 |
| 查看经营 | 第一轮营业开始了。去橱窗经营页看看状态，学会关注客流和收益。 | 打开“橱窗经营”。 | 看看经营状态 |
| 完成 | 很好，你已经独立走完了第一轮开店流程。接下来按自己的想法经营这家店吧。 | 引导已完成。 | 结束引导 |

动态等待文案仍由运行状态决定，但通过对话目录或独立状态说明提供，不重新把完整台词写回 `main_view.gd`。至少包括：

- 产出尚未成熟时提示等待成熟并手动收获。
- 米浆饮正在制作时提示等待制作完成。
- 当前营业未结束、橱窗布局锁定时解释暂时不能调整。
- 当前已有营业轮次时解释为什么不能再次开始营业。

## 6. 主动展开与收起规则

以下情况主动展开：

- 新游戏首次进入引导。
- 引导步骤发生真实推进。
- 玩家跳过本步后进入下一步。
- 玩家点击收起状态的外婆图标。
- 进入完成步骤并显示祝贺。
- 玩家选择“再来一遍”后回到采购步骤。

以下情况不主动展开：

- 同一步骤内普通 UI 刷新。
- 目标控件在动态重建后重新解析。
- 倒计时或生产状态每帧刷新。
- 正式弹窗关闭后恢复引导；此时恢复阻塞前的展开或收起状态。

玩家点击主按钮后收起当前对话，并把当前步骤写入 `tutorial_guide_dialogue_acknowledged_step`。收起行为触发保存。重新载入同一步骤时只显示外婆图标；步骤变化后旧值自然失效。重新引导时清空该字段。

## 7. 异常与边界处理

- 当前目标不存在、不可见或尺寸为零：隐藏箭头，保留外婆图标和可重看的对话，不推进步骤。
- 正式弹窗出现：临时隐藏引导层，不修改已读状态和业务进度。
- 正式弹窗关闭：恢复此前展开或收起状态，不重新播放主动对话。
- 对话目录缺少步骤：使用安全兜底台词和行动提示，同时保持业务步骤不变。
- 旧存档没有 `tutorial_guide_dialogue_acknowledged_step`：按未读处理。
- 旧版指针引导已经正常结束、且尚无 `tutorial_guide_content_version` 的存档：首次加载 NPC 对话版时重启一次引导，但保留经营资源和业务进度；明确跳过整套引导的存档仍保持跳过。
- “跳过本步”：只调用现有 `TutorialProgress.skip_current_step()`，不赠送资源、不解锁配方、不伪造任务事件。
- 引导完成：背景保持不可操作，直到玩家选择结束或重新引导。

## 9. 完成标准

- 新游戏通过外婆对话开始引导，不再出现旧的小型文字提示框。
- 对话主动展开、确认后收起、点击左下角外婆图标可重看。
- 展开对话与橱窗区域等宽，高度紧凑，不改变橱窗网格尺寸。
- 十个真实操作步骤、跳过本步、弹窗阻塞、保存恢复、完成与重新引导均符合本文契约。
- 所有相关聚焦自检通过，且未改动 `project-rest-new` 之外的项目。
