# 主页面背景替换规格

## 目标

为 `project-rest-new` 的主页面加入与现有“邻里甜品店”皮肤一致的全屏背景，避免改变现有经营、橱窗、工作台和弹窗的布局或交互。

## 选定素材

使用 `res://resources/ui/skin/neighborhood_dessert/runtime/panel_main_normal.png`。

该运行纹理已移除生成源图四周的透明留白，浅奶油底与金色外框可与当前的深棕文字、金色按钮和面板视觉保持一致。

## 场景改动

在 `scenes/Main.tscn` 的 `Main` 根节点下新增一个全屏 `NinePatchRect`：

- 作为第一个子节点，确保位于全部现有内容和反馈层之下；
- 锚定全屏，随窗口伸缩；
- 使用选定运行纹理，并以 30 像素九宫格边距拉伸，完整保留四角和边框厚度；
- 禁用鼠标接收，不能拦截现有点击与拖拽。

## 非目标

- 不更改主题资源、字体、颜色或任何既有面板皮肤；
- 不新增运行时脚本、存档字段或交互；
- 不调整 `Root`、橱窗、工作台、顶栏和弹窗的现有几何。

## 验证

新增一个聚焦场景契约自检，断言背景节点、纹理引用、全屏锚点、鼠标穿透和节点层级；然后使用项目规定的 `--log-file` 参数运行 Godot 无界面自检。
