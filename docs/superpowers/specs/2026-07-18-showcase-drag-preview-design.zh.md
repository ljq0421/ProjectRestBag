# 橱窗配方拖拽预览修复设计

## 目标

修复橱窗内已上架配方的拖拽预览：

- 鼠标位于橱窗区域内时，拖拽预览完全透明，不显示图标或文字。
- 具备真实下架资格的商品被拖出橱窗区域时，只显示醒目的“下架”字样。
- 不具备下架资格的商品即使被拖出橱窗，也不显示任何预览内容。

## 范围

本次只修改橱窗商品的瞬态拖拽预览，不修改商品移动、多格商品抓取偏移、营业中售罄判定、实际下架或替换逻辑。库存面板、产出格和道具拖拽继续使用现有通用预览。

## 设计

橱窗格使用专用拖拽预览控件。预览只接收橱窗的全局矩形和当前商品是否具备真实下架资格，不接收或渲染配方图标。预览控件在拖拽期间读取鼠标位置：只有允许下架且鼠标不在橱窗矩形内时，才显示“下架”；其他状态保持完全透明。

`main_view.gd` 在配置橱窗商品拖拽时提供橱窗边界，并复用真实下架判定作为预览许可；现有拖拽数据、移动规则、多格抓取偏移和拖拽结束回调保持不变。

## 验证

采用红—绿回归：

1. 将拖拽预览加入真实场景树后，鼠标在橱窗内时没有任何可见内容。
2. 可下架商品被拖到橱窗外时只显示“下架”。
3. 普通可移动商品即使指针位于橱窗外，也没有任何可见内容。
4. 运行现有售罄拖出和橱窗格视觉自检，确认实际下架语义及格子视觉没有回归。
