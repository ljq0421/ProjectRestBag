# 《花屿洋果子店》游戏策划案
（参考《洋果子店ROSE2》核心玩法，面向PC端优化的治愈系模拟经营游戏）

## 一、游戏概述
### 1.1 基本信息
- **游戏名称**：花屿洋果子店
- **游戏类型**：治愈系模拟经营+配方收集养成
- **目标平台**：PC（Steam、WeGame），支持键鼠操作与手柄适配
- **游戏体量**：单机买断制，基础版包含4大季节、120+配方、8个NPC、5张场景地图；后续通过DLC拓展内容
- **游戏时长**：主线流程约20-30小时，全收集约60-80小时

### 1.2 核心定位
以《洋果子店ROSE2》的「食材收集-配方盲研-甜品售卖-内容解锁」核心循环为基础，针对PC端放大**自由装修、批量经营、剧情沉浸、图鉴收藏**四大优势，去除手游体力、抽卡等限制，打造一款低压力、高治愈、长线收集乐趣充足的单机经营游戏。

### 1.3 设计理念
1. **保留原作核心乐趣**：配方盲盒式研发、食材组合逻辑、季节限定内容、轻松无负担的经营节奏
2. **PC端体验升级**：大屏图鉴系统、店铺自由布局、批量制作功能、多存档位支持
3. **强化沉浸感**：补充小镇世界观与NPC个人剧情，丰富场景互动细节，弱化数值焦虑
4. **纯正向反馈**：无失败惩罚，研发失败仅给提示，经营无破产风险，主打放松治愈

### 1.4 目标用户
- 喜爱《洋果子店》系列的休闲经营玩家
- Steam平台偏好治愈系、收集类单机游戏的用户
- 喜欢碎片化+长线挂机结合玩法的上班族、学生群体

## 二、世界观与背景设定
### 2.1 故事背景
玩家收到一封远方来信，继承了素未谋面的外婆留在「花屿小镇」的一间老旧洋果子店。这座临海的小镇四季分明，居民友善，周边的森林、牧场、海岸孕育着丰富的天然食材。
玩家的目标是从零重启这间甜品店，研发各式各样的美味洋果子，招待小镇居民，在四季流转中慢慢了解外婆的故事，与小镇的人们产生羁绊，最终让这间小店成为花屿镇的温暖地标。

### 2.2 核心场景设定
| 场景名称 | 功能定位 | 可获取内容 |
|----------|----------|------------|
| 洋果子店 | 核心经营主场景 | 制作甜品、上架售卖、研发配方、店铺装修 |
| 小镇商业街 | 采购与社交 | 基础食材商店、家具店、NPC日常互动 |
| 后山森林 | 野外采集 | 浆果、坚果、蜂蜜、蘑菇、季节限定食材 |
| 临海牧场 | 食材获取 | 牛奶、鸡蛋、奶酪、黄油等乳制品 |
| 海岸浅滩 | 采集与探索 | 海盐、柠檬、椰果、特殊海产食材 |
| 小镇广场 | 活动与事件 | 节日活动、限时集市、随机NPC事件 |

## 三、核心玩法与游戏循环
### 3.1 核心玩法拆解
1. **配方收集**：通过食材组合盲试研发新配方，解锁图鉴，是游戏核心目标
2. **食材获取**：商店采购、野外采集、自种养殖、NPC赠送、活动奖励多渠道获取
3. **甜品制作**：消耗食材制作成品，支持多操作台并行、批量制作
4. **店铺经营**：上架甜品售卖、接待顾客、完成订单、升级店铺、自由装修
5. **小镇互动**：与NPC交友、解锁剧情、获取专属奖励，参与小镇节日活动

### 3.2 日常游戏循环
**短循环（5-10分钟）**：
收取成熟食材/采购食材 → 制作补货 → 接待几波顾客 → 尝试1-2次配方研发 → 领取订单奖励

**中循环（30-60分钟）**：
外出采集一轮食材 → 批量制作多类甜品 → 整理店铺货架/调整装修 → 推进1个NPC剧情 → 解锁新的店铺功能

### 3.3 长期成长循环
店铺升级 → 解锁新场景/新食材池 → 解锁更多配方品类 → 提升NPC好感获取稀有配方 → 完成季节活动收集限定内容 → 冲击全图鉴收集成就

## 四、核心系统设计
### 4.1 食材系统
#### 4.1.1 食材分类
共分为5大类，总计80+种基础食材+20种季节限定食材：
- **基础原料**：面粉、白砂糖、鸡蛋、黄油、酵母、盐等通用基础材料
- **蔬果杂料**：草莓、蓝莓、抹茶、红豆、栗子、南瓜、可可粉等风味原料
- **乳制品**：鲜奶油、牛奶、奶酪、酸奶、炼乳等
- **特殊食材**：樱花、桂花、金箔、玫瑰、蜂蜜、巧克力等稀有/装饰类食材
- **饮品类原料**：红茶、咖啡、抹茶粉、气泡水等

#### 4.1.2 获取方式
1. **商店采购**：小镇食材店每日刷新基础食材，部分中级食材固定售卖，随店铺等级解锁更多品类
2. **野外采集**：不同场景产出对应食材，采用轻度点击交互玩法（如采摘草莓需点击成熟果实），每日有采集次数上限，随升级提升
3. **后院种养**：解锁店铺后院后，可种植蔬果、饲养家禽，定时收获，支持一键收取（PC端专属优化）
4. **NPC馈赠**：NPC好感度提升后，会赠送专属稀有食材
5. **季节/活动限定**：仅在对应季节或节日活动中可获取，是限定配方的核心材料

### 4.2 配方研发系统
（完整继承《洋果子店ROSE2》的核心乐趣，优化PC端交互）
#### 4.2.1 研发规则
- 在研发台放入1-4种食材，点击「尝试制作」即可发起研发
- 组合正确则解锁对应配方，记录食材配比与制作参数
- 组合错误给出梯度提示：「完全不搭的组合」「好像还差一点东西」「感觉快要成功了」，引导玩家摸索
- 每次研发消耗少量食材，无其他惩罚，降低试错压力

#### 4.2.2 配方体系
总计120+基础配方+30+限定配方，分为5大品类：
1. **烘焙点心**：蛋糕、曲奇、泡芙、挞派等烤箱类甜品
2. **和式果子**：大福、羊羹、铜锣烧、樱饼等日式点心
3. **冰品饮品**：冰淇淋、布丁、苏打、咖啡、茶饮等
4. **面包主食**：餐包、吐司、可颂、三明治等
5. **节日限定**：仅对应季节/节日解锁的特殊配方

#### 4.2.3 图鉴系统（PC端重点优化）
- 大屏分类图鉴，支持按品类、难度、获取方式筛选，支持关键词搜索
- 已解锁配方显示完整食材、制作时间、基础售价、解锁来源
- 未解锁配方显示模糊剪影与提示线索，保留收集悬念
- 支持「配方笔记」功能，玩家可自行标注研发思路与食材组合

### 4.3 甜品制作系统
#### 4.3.1 基础流程
选择已解锁配方 → 确认制作数量 → 消耗对应食材 → 占用操作台倒计时 → 制作完成自动入库
- 初始1个基础操作台，店铺每升2级解锁1个新操作台，最多支持6台同时工作
- 不同配方制作时长不同，简单配方10-30秒，复杂配方2-5分钟

#### 4.3.2 PC端专属功能
- **批量制作**：解锁「高效厨具」后，可一次制作最多10份同款甜品，减少重复操作
- **制作队列**：可提前编排制作顺序，操作台自动按队列执行，适合挂机经营
- **品质分级**：制作有小概率产出「特级品质」甜品，售价提升50%，顾客满意度更高；升级厨具可提升特级品概率

### 4.4 店铺经营与装修系统
#### 4.4.1 售卖玩法
- 甜品上架至货架后，顾客自动进店选购，完成交易获得金币与店铺经验
- 货架有格子上限，升级店铺可解锁更多货架与陈列位
- 顾客类型：普通居民、学生、上班族、游客、美食评论家；美食评论家消费高，还会提升店铺声望
- **订单系统**：每日刷新5个普通订单+1个NPC特殊订单，按要求交付甜品可获得额外金币与好感度

#### 4.4.2 自由装修系统（PC端核心特色）
- 俯视角2.5D店铺场景，支持鼠标拖拽摆放家具与装饰
- 家具分类：货架类、操作台类、桌椅类、装饰类、功能类
- 装修加成：不同风格的家具会影响客流量、顾客停留时间、小费概率
- 主题套装：和风、欧式复古、可爱马卡龙、森系等多种装修主题，集齐套装有额外加成
- 支持保存3套装修方案，一键切换

#### 4.4.3 店铺升级
- 消耗金币与少量特殊材料升级店铺等级
- 升级解锁：新操作台、新货架、后院功能、新食材品类、新配方池、新场景

### 4.5 小镇NPC与社交系统
#### 4.5.1 NPC设定
初始8名核心NPC，每人有独立身份、性格、喜好甜品与完整个人剧情，例如：
- 森田大叔：牧场主人，性格豪爽，喜欢重油类面包，好感满级赠送稀有奶酪配方
- 小樱：高中女生，喜欢可爱风甜品，常来店里写作业，好感满级赠送樱花限定食材
- 老馆长：图书馆馆长，偏爱传统和果子，会分享古籍里的隐藏配方

#### 4.5.2 互动玩法
- 赠送甜品提升NPC好感度，赠送其喜好的甜品好感翻倍
- 好感度分为5级，每级解锁新对话、个人剧情片段与对应奖励
- NPC会随机出现在小镇不同场景，触发偶遇事件，解锁额外支线
- 部分隐藏配方仅能通过NPC好感满级获取

### 4.6 四季与节日活动系统
#### 4.6.1 四季循环
- 游戏内30天为一个季节，四季循环，与现实时间无关，可手动调整流速
- 春季：樱花主题，解锁樱花系列食材与配方，小镇樱花飘落特效
- 夏季：海洋主题，解锁薄荷、椰果等食材，冰品销量提升
- 秋季：丰收主题，解锁栗子、红薯、南瓜等食材，节日活动密集
- 冬季：冰雪主题，解锁草莓、巧克力等食材，热饮销量提升

#### 4.6.2 节日活动
每个季节对应1-2个专属节日，每个活动持续7天：
- 春季：樱花祭——限时采集樱花，兑换限定装饰与配方
- 夏季：夏日祭——庙会摆摊玩法，挑战售卖目标获取奖励
- 秋季：美食节——NPC品鉴大赛，提交指定甜品赢取稀有食材
- 冬季：圣诞季——限定姜饼人系列配方，装饰圣诞主题店铺

### 4.7 收集与成就系统
- **四大图鉴**：食材图鉴、配方图鉴、NPC图鉴、装饰图鉴，全收集为终极目标
- **成就系统**：分为经营类、收集类、互动类、挑战类四大板块，完成成就获得金币、稀有装饰、专属称号
- **外婆的日记**：随游戏进度逐步解锁外婆的日记片段，补全故事背景，串联所有剧情线

## 五、数值框架（简版）
### 5.1 经济系统
- **初始资源**：500金币、基础食材若干、1个操作台、2组货架
- **金币产出**：日常售卖（70%）、订单奖励（20%）、成就/活动（10%）
- **金币消耗**：食材采购、店铺升级、家具购买、研发消耗（少量）
- **数值原则**：无破产风险，金币始终正向产出；前期节奏快，解锁反馈密集；后期偏向收集，金币用于装修与活动

### 5.2 成长节奏
| 游戏阶段 | 店铺等级 | 核心内容 | 游戏时长 |
|----------|----------|----------|----------|
| 新手期 | 1-3级 | 解锁基础配方、学会研发与售卖、解锁商业街 | 1-2小时 |
| 成长期 | 4-8级 | 解锁森林/牧场、批量制作、后院、第一个NPC剧情 | 8-10小时 |
| 丰富期 | 9-15级 | 解锁海岸、全部NPC、四季系统、装修功能 | 20-30小时 |
| 收集期 | 16级以上 | 全图鉴收集、全好感满级、全成就、节日限定内容 | 30+小时 |

## 六、美术与音效设计
### 6.1 美术风格
- 整体延续《洋果子店ROSE2》的治愈手绘风，采用柔和马卡龙配色，线条圆润温暖
- PC端支持1080P/2K分辨率，场景与甜品细节精度升级，突出食物的质感与诱人度
- 动态表现：烤箱蒸汽、飘落的花瓣、顾客走动动画、猫咪打盹等细节，增强场景活力
- 角色采用Q版二头身比例，风格可爱统一，NPC造型辨识度高

### 6.2 界面设计
- 键鼠优先：左侧功能菜单栏、中间主场景、右侧信息面板，支持鼠标悬停查看详情
- 交互轻量化：常用功能设置快捷键，图鉴、背包支持滚轮翻页，装修支持缩放与旋转
- 信息层级清晰：经营数据、倒计时、任务提示分布合理，不遮挡主场景

### 6.3 音效与音乐
- 背景音乐：轻柔钢琴+木吉他配乐，四季对应不同曲风，节日切换专属BGM
- 音效细节：烤箱叮声、切菜声、顾客脚步声、风铃音、雨声等环境音，增强沉浸感
- 无过度刺激音效，整体音量平缓，符合放松治愈的定位

## 七、PC端专属优化设计
1. **操作适配**：键鼠拖拽装修、快捷键快速制作、一键收取/补货、批量选中操作
2. **大屏适配**：多面板同屏显示，图鉴与背包可放大查看，支持窗口化/全屏切换
3. **存档系统**：本地3个存档位+Steam云存档，支持随时存档读档
4. **创意工坊支持（后续更新）**：开放玩家自制配方、装修皮肤、MOD的上传与分享
5. **成就系统**：接入Steam成就，与游戏内成就互通

## 八、商业化与运营规划
### 8.1 收费模式
- 本体买断制，定价亲民（对标同类国产单机经营游戏）
- 无内购、无广告、无体力限制，纯单机体验
- 后续推出付费DLC，每个DLC包含新场景、新NPC、新配方包、新装修主题

### 8.2 内容更新规划
- 首发版本：4大季节、120+配方、8名NPC、5个核心场景
- 免费更新：节日限时活动复刻、bug修复、少量新配方
- 付费DLC1「温泉街篇」：新增温泉街场景、3名新NPC、30+和果子配方、和风装修包
- 付费DLC2「海滨咖啡店篇」：新增咖啡店经营线、饮品配方拓展、海滨装修主题

## 九、开发阶段规划
1. **原型阶段（4周）**：完成核心玩法原型（研发+制作+售卖），验证核心循环乐趣
2. **Demo阶段（8周）**：完成前3级内容、基础场景、10个配方、新手引导
3. **正式开发（16周）**：完成全部系统、全量配方与剧情、美术与音效接入
4. **测试优化（4周）**：内部测试、数值调优、bug修复、PC端适配优化
5. **上线筹备（2周）**：商店页制作、宣发素材、平台审核
