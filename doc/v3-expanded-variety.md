## 扩容目标

上一版主要补充了字段与实现说明；本版重点扩充内容种类：

- 食材：从 21 个扩展到 36 个。
- 配方：从 18 个扩展到 36 个。
- 设备：仍保持 4 类，避免扩大系统复杂度。
- 店铺等级：仍保持 1-5 级，新增内容按等级分批解锁。
- 鱼塘：`sea_salt` 不再只是测试材料，新增海盐焦糖、海盐奶盖等配方，让鱼塘有真实用途。

设计原则：

- 新增食材覆盖水果、风味、调味、基底、配料、草本、饮品感材料。
- 新增配方尽量复用原设备：搅拌台、烤箱、冷藏柜、煎烤盘。
- 每个等级都有可研发的新目标，避免玩家在中后期只刷钱。
- 不引入新 UI 大模块，只扩充采购、研发、生产、图鉴的数据池。

## 实现注意

1. 推荐实现时使用自动校验：配方解锁等级不得低于所需设备和材料的解锁等级。
2. 新增 `低负担`、`软糯`、`咸香`、`香气` 标签后，顾客偏好表也应增加对应偏好，否则这些标签只影响图鉴，不影响营业评分。
3. 建议最终以脚本校验结果为准：食材 ID 唯一、配方 ID 唯一、配方材料全部存在于食材或中间成品中。
