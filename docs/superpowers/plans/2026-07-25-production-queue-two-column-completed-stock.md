# Production Queue Two-Column Completed Stock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep the production workbench at `820px` wide while moving finished, listable product stock into a `104px` left rail and keeping craftable/active/missing work in a `708px` right queue.

**Architecture:** `main_view.gd` remains the source of truth for queue ownership and returns two mutually exclusive entry arrays: `completed_entries` and `queue_entries`. Scene-declared workbench columns render those arrays through one focused completed-stock cell component and the existing production row component; runtime ticks update only right-side progress, while inventory or completion events rebuild structural ownership.

**Tech Stack:** Godot 4.6.1, GDScript, `.tscn` scene resources, existing `RecipeIconService`, existing `scripts/output_cell.gd` drag protocol, headless SceneTree self-checks.

## Global Constraints

- Work only in `D:\Project\ProjectRest\project-rest-new`.
- Preserve the workbench dimensions `820×858px`, header `820×54px`, and body `820×794px`.
- Body widths are exactly `104px + 8px + 708px`.
- Completed stock appears only when a durable production-ready record exists and product inventory is greater than `0`.
- A completed recipe appears only in the left rail; it is excluded from the right queue and from “制作全部”.
- Product inventory reaching `0` removes the left cell and returns the recipe to the correct right-side band.
- Left and right product canvases are `68×68px`; recipe products use the `128×128` base icon surface, not the `32×32` action surface.
- The left tooltip contains only name, `库存：N`, `售价：N`, and `标签：…`; it contains no drag instruction and no multiplication sign.
- Missing materials use neutral colors and retain icon, name, and `owned/required` numbers.
- Do not implement recipe tag tabs in this plan.
- Keep `inventory_product` and `manual_list_source: "drag"` unchanged.
- Every Godot headless command must pass a concrete writable log path under `$env:TEMP`; never use `NUL`.
- Do not stage or modify unrelated untracked files under `resources/ui/icons_v1`.
