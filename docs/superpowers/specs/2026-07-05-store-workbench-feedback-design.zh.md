# 店面与工作台正反馈改造设计

## 背景

当前游戏已经具备“生产页上架后立即营业”的行为，但正反馈主要落在底部状态栏和右侧日志中。玩家完成生产、上架、出售后，画面上的空间关系不够直接：工作台产出与店面售卖被页面切换隔开，橱窗和收银反馈不够持续可见。

本次改造目标是把核心闭环固定在同一屏：

`工作台生产货物 -> 店面橱窗上架 -> 店面出售并结算`

玩家不需要切换到单独的橱窗页才能看到售卖结果；店面始终在上方展示，工作台始终在下方承载操作。

## 总体布局

主界面保留顶部资源栏，并把全局入口固定在顶部：

- `任务`
- `库存`
- `图鉴`

主体区域改为上下两部分：

- 上方 40%：`店面`
- 下方 60%：`工作台`

顶部资源栏不计入 40% / 60% 的主体比例。顶部栏继续显示金币、口碑、店铺等级等资源信息。

## 店面区域

店面区域从左到右分为三块：

- 左侧 15%：`开门动画区`
- 中间 60%：`橱窗`
- 右侧 25%：`收银台`

### 开门动画区

左侧 15% 不展示顾客队列，也不展示顾客喜好。

该区域只作为正反馈动画预留：

- 上架并营业时可播放开门动画。
- 售出商品时可播放迎客、门铃、成交等轻量反馈。
- 当前实现阶段可以先用静态占位和最近营业提示，后续再替换为动画资源。

### 橱窗

橱窗展示当前上架商品。

每个商品格展示：

- 商品图标或名称。
- 当前库存。
- 空槽或未解锁槽状态。

鼠标悬停商品格时展示商品细节：

- 商品名称。
- 售价。
- 库存。
- 标签。
- 最近售卖结果。

橱窗是持续可见反馈区，不再作为独立主页面入口。玩家在工作台完成上架后，橱窗立即刷新。

### 收银台

收银台分为多个收银台位，并按等级或后续进度依次解锁。

每个收银台位展示：

- 已解锁或待解锁状态。
- 最近一次营业的售出数量。
- 金币变化。
- 口碑变化。

当前阶段不需要实现复杂排队逻辑。收银台的主要作用是把“商品真的卖出去了”变成明显的画面反馈。

## 工作台区域

工作台保留四个功能 tab：

- `采购`
- `产出`
- `研发`
- `生产`

这四个 tab 竖向排列在工作台左侧。右侧展示当前 tab 的内容。

现有页面功能映射如下：

- `采购`：保留现有采购分类 tab 和购买逻辑。
- `产出`：保留现有产出地点 tab、生产格、背包格、拖拽、收获、暂停、解锁逻辑。
- `研发`：保留现有材料多选、工具选择和研发逻辑。
- `生产`：保留现有制作和上架逻辑，并强化上架后的店面反馈刷新。

原左侧主导航不再承担页面切换。`任务`、`库存`、`图鉴` 改为顶部全局入口。现有升级能力不在本次布局核心内；实现时可先保留为内部功能入口或后续并入任务/店面进度反馈，但不占用工作台四个主 tab。

## 正反馈流程

生产页点击上架后，流程应连续发生：

1. 从成品库存中选择商品。
2. 商品进入第一个可用橱窗槽。
3. 店面橱窗立即刷新，显示上架商品和库存。
4. 执行一次营业结算。
5. 开门动画区显示营业触发反馈。
6. 收银台显示售出数量、金币增加、口碑增加。
7. 状态栏保留一句汇总文案。

失败反馈也要保持可见：

- 没有可用橱窗槽时，状态栏提示原因。
- 成品库存不足时，状态栏提示原因。
- 营业售出为 0 时，收银台仍显示“本轮未售出”，避免玩家误以为没有触发。

## 数据与职责边界

本次设计优先调整界面结构和反馈呈现，不改变核心经济规则。

- `scenes/Main.tscn` 负责固定布局节点：顶部栏、店面区、工作台区、竖排 tab、橱窗格、收银台反馈容器。
- `scripts/main_view.gd` 负责绑定已有节点、刷新当前 tab、刷新店面展示、处理按钮和状态反馈。
- `scripts/shop_simulation.gd` 继续负责营业结算。
- `scripts/game_state.gd` 继续保存库存、橱窗槽、金币、口碑、等级和日志。

如果需要展示最近一次售卖结果，优先从 `ShopSimulation.run_business()` 返回值中生成 UI 状态，不为了 UI 单独改变营业规则。

## 测试范围

自检应覆盖真实 ready 路径，而不只是场景能实例化。

需要新增或更新的检查：

- 主场景包含顶部 `任务`、`库存`、`图鉴` 常驻入口。
- 主体区域包含 `店面` 与 `工作台` 两个固定区域。
- 店面区域包含 `开门动画区`、`橱窗`、`收银台`，并保持 15% / 60% / 25% 的结构意图。
- 工作台区域左侧竖排 `采购`、`产出`、`研发`、`生产` 四个 tab。
- 切换工作台 tab 时，店面区域不消失。
- 生产页上架商品后，橱窗展示刷新。
- 生产页上架并营业后，收银台展示售出数量、金币变化、口碑变化。
- 售出为 0 时，收银台仍展示本轮营业结果。

最终验证仍以 `tests/mvp_self_check.gd` 为主要 headless gate。
