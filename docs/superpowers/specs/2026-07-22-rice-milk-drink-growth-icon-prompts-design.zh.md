# 米浆饮四档图标提示词设计

日期：2026-07-22

## 仓库依据

- 配方 ID：`rice_milk_drink`
- 配方名称：米浆饮
- 当前原料：`rice`、`spring_water`
- 当前标签：经典、清爽
- 展示布局：竖杯款，`2x1`（2 行 × 1 列），四档共用该布局并支持旋转
- 画面规格：512×512 px，纯 `#00FF00` 键控绿背景

旧设计文档曾写入白糖，但当前 `scripts/catalog.gd` 不含 `sugar`。以下提示词以当前运行数据为准，禁止方糖、砂糖、牛奶及其他配方外原料。

## 统一设计约束

四档保持“玻璃瓶装米浆”的连续身份，以瓶型规整度、液体纹理和稻米/泉水装饰数量体现成长。保持竖杯款的细长比例；主体高度约占画布 94%–97%，瓶体本身宽度约占画布 56%–68%，高阶款可由左右装饰将整体视觉宽度扩展至约 88%–94%。最外侧可见像素距离画布边缘约 8–12 px，所有瓶口、瓶底、描边、稻米和水滴必须完整，不得触边或截断。

```text

主体设计：单个略显手作感、圆润矮胖但仍保持竖向比例的透明玻璃米浆瓶；宽瓶肩、轻微外翻的圆瓶口、厚实完整的玻璃瓶底。瓶内装浅奶油米白色米浆，只有一条柔和的淡蜂蜜金旋涡，质地顺滑、温暖、可口。瓶底外侧只放 2–3 颗小巧饱满的白色稻米粒和一颗清透浅青色泉水滴作为紧贴主体的微型原料提示；装饰不能成为第二份食物。不要牛奶、奶盒、糖、方糖、水果、薄荷或任何其他配方外原料。

画风与配色：严格采用当前游戏的 2D 卡通食物图标风格，略俯视正面视角，圆润夸张的游戏可读轮廓，深可可棕色描边，赛璐璐明暗结合少量柔软手绘厚涂。主色为奶油米白、暖蜂蜜金、透明玻璃白；只用少量清透青绿色表现泉水与玻璃冷高光。整体温暖明亮、干净清爽，不要照片感、写实材质、3D 渲染或塑料玩具感。

构图与边界：严格输出 512×512 px。保持竖杯款 2 行 × 1 列的细长连续轮廓，主体垂直居中，高度占画布约 96%，瓶体宽度约占 66%。放大主体，让瓶口最高点、瓶底最低点及最外侧稻米/水滴距离画布边缘约 8–12 px；四周保留一圈清晰绿色，不得截断瓶口、瓶底、描边、高光或装饰，不得让任何轮廓触碰画布边线。

背景：整张画布使用均匀、纯净、完全不渐变的键控绿 #00FF00。绿色只属于背景，不得反射、染色或渗入主体；不要透明背景。

禁止项：不要场景、桌面、托盘、杯垫、投影、落地阴影、外发光、粒子、烟雾、第二个容器。不要文字、数字、字母、Logo、水印、边框、徽章、旗帜、吊牌、皇冠、星星、丝带。只生成一个完整主体，所有部分必须在画布内。
```

## 自检结论

- 四档均严格使用当前配方中的稻米与泉水，没有沿用旧文档中的白糖。
- 四档均保持竖杯款 `2x1` 身份，没有改变展示占格。
- 四档成长差异依次落在瓶型规整度、流纹层数和原料装饰数量上，不依赖文字、徽章或皇冠表达等级。
- 所有提示词均明确采用纯 `#00FF00` 背景，并同时约束主体接近边缘和完整不截断。
